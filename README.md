# Counterrotating Motion

Research archive and continuing analytical study of counterrotating charged particles in a two-frequency 24-electrode RF trap.

The [V17C research catalog](research/v17c/) contains the complete published scientific data, code, reports, and figures from the latest historical branch. Fourteen unchanged `research/v17c*` branches retain earlier and divergent results. The root `migration/` directory documents source commits, per-file SHA-256 checksums, verification, and recovered local files.

Migration audit: [report](migration/MIGRATION_REPORT.md), [manifest](migration/MIGRATION_MANIFEST.json), [branch map](migration/BRANCH_HISTORY_MAP.md), and [file integrity](migration/FILE_INTEGRITY_REPORT.md).

Latest report: [V17C.22 stable counterrotation theory](research/v17c/v17c_22/STABLE_COUNTERROTATION_THEORY_RU.md). The published long-lived counterrotation has **not** established a mathematically proven attracting torus.

New analytical reduction and mechanism study: [report](reports/THREE_PARAMETER_COUNTERROTATION_RU.md), [physical explanation](theory/PHYSICAL_MECHANISM_RU.md), [dimensionless equations](theory/NONDIMENSIONALIZATION.tex), and [Overleaf draft archive](counterrotating-motion-overleaf.zip). The draft has not been compiled with pdfLaTeX because that engine and the Russian T2A fonts are unavailable in the current Windows environment.

V2 radius-eliminated leading-order criterion: [theory and limits](reports/THREE_PARAMETER_THEORY_RU.md), [boundary validation](reports/BOUNDARY_VALIDATION_RU.md), [Reynolds audit](reports/REYNOLDS_VALIDITY_RU.md), [physical mechanism](reports/PHYSICAL_MECHANISM_RU.md), [numerical validation](reports/NUMERICAL_VALIDATION_RU.md), [new Chaos-layout manuscript](latex/chaos/main.tex), and [Overleaf project ZIP](Counterrotating_Motion_Chaos_RU_Overleaf.zip). The new Russian ZIP remains `UNVERIFIED_BUILD` until it is built and inspected with pdfLaTeX.

Historical branch commits also contain the source 12-electrode project's root files. This `main` branch keeps the V17C catalog as the independent research project; historical commits remain accessible unchanged.
