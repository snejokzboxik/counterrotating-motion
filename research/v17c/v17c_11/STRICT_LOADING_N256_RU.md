# V17C.11 — строгая независимая проверка загрузки, N=256

## Постановка и целостность

Проверены три заранее выбранных протокола загрузки к неизменной конечной конфигурации local15: P2 #505, P2 #353 и P7 #292. Каждый получил одни и те же 256 начальных состояний в ансамблях rest, weak, wide и edge. Четыре независимых seed равны `20261301–20261304`; контрольные суммы координат и RF-фаз записаны в `strict_loading_holdout_n256/holdout_metadata.json`.

Выполнено 3,072 интегрирования FP64 RK4, 96 шагов на период основной RF-компоненты, 200 периодов релаксации и 15,000 измеряемых периодов после окончания загрузки. Протокол #505 завершался за 3 RF-периода, #353 — за 10, #292 — за 1.84451 периода. Полные trajectories, стартовые данные и параметры находятся в JSONL/NPZ/JSON рядом с этим файлом.

Повторный аудит нашёл 3,072 уникальные строки, по 256 строк на каждую пару «протокол—ансамбль». Все SHA-256 массивов совпали с метаданными; стартовые координаты и обе RF-фазы побитово совпадают между протоколами. Для каждой строки проверены флаг успеха и категория. Для CR-успехов дополнительно проверены удержание, противоположные знаки в трёх поздних окнах, минимум 10 оборотов каждой частицы и отсутствие конечного контакта сфер. Скрипт: `audit_loading_holdout.py`; машинный результат: `strict_loading_holdout_n256/holdout_integrity_audit.json`.

Лучший робастный точечный результат — #505. Он превосходит #353 на 0.39 процентного пункта по `J_robust`; преимущество по edge относительно #292 составляет 1.95 п.п. На общих frozen starts агрегированные двусторонние exact McNemar-тесты не показывают убедительного различия: #505 против #353 `p=0.188`, #505 против #292 `p=0.878`. Поэтому #505 — эмпирический лидер среди этих трёх, а не статистически доказанный универсальный оптимум. 95% не достигнуты ни по робастной метрике, ни по wide/edge.

## Удержание и причины неуспеха

| Протокол | Retained: rest / weak / wide / edge | Контакт конечной частицы со стенкой | Осевая неоднозначность |
|---|---:|---:|---:|
| #505 | 254/256 / 255/256 / 237/256 / 216/256 | 62 | 5 |
| #353 | 248/256 / 254/256 / 238/256 / 214/256 | 70 | 6 |
| #292 | 256/256 / 256/256 / 239/256 / 213/256 | 60 | 9 |

Показатель удержания включает осево-неоднозначные траектории; они не считаются CR-успехом. Все неуспехи holdout относятся к контакту со стенкой или осевой неоднозначности; зарегистрированных межчастичных контактов нет. Стеночные потери ранние: счётчик завершённых RF-периодов до остановки — 0–1 у #505, 0 у #353 и 0–2 у #292. Edge остаётся главным ограничением. Для #505 распределение неуспехов в edge — 40 стеночных контактов и 3 осево-неоднозначных траектории.

## Направления, частоты и расстояния

Все 2,860 строгих успехов трёх протоколов имеют знак `(+,-)`; `(-,+)` не встретилось. Это удовлетворяет критерию встречного вращения, но показывает асимметрию наблюдённого бассейна направлений. Для #505 средние частоты по успешным траекториям составили:

| Ансамбль | Частица 1 | Частица 2 | Средние полные обороты после загрузки |
|---|---:|---:|---:|
| Rest | +154.232 Hz | −100.192 Hz | +23.135 / −15.029 |
| Weak | +154.227 Hz | −100.192 Hz | +23.134 / −15.029 |
| Wide | +154.223 Hz | −100.193 Hz | +23.133 / −15.029 |
| Edge | +154.222 Hz | −100.193 Hz | +23.133 / −15.029 |

Для успешных #505 минимальное расстояние между центрами на траектории имело минимум `0.00970 R`; сумма радиусов частиц равна `0.00209 R`. Среднее минимальное межцентровое расстояние по успешным траекториям — около `0.193 R`. Частоты получены развёрткой угла относительно оси ловушки; критерии и поздние окна перепроверены отдельным аудитом.

## Вывод

Общий непрерывный протокол включения заметно удерживает почти все rest/weak старты, но не устраняет узкое место на краю апертуры. В заданной выборке #505 — наиболее робастный из трёх по минимальной вероятности, однако оценка edge `83.20%` и её интервал не поддерживают цель 95–99%. Дальнейшая оптимизация протоколов остановлена; эти данные служат базой для следующего этапа с двумя взаимодействующими трёхчастичными вращающимися кристаллами.


Ограничение дизайна: в каждой группе использован один randomized Sobol scramble, не IID выборка и не несколько независимых scramble. Wilson и McNemar в этом отчёте — номинальные IID-приближения; они не калиброваны как строгие доверительные интервалы для randomized-QMC дизайна. Точечные доли и парные счёты показывают наблюдаемый эффект на этих стартах; формальные p-values не следует трактовать как сохранённую частотную оценку различия.

Граница постановки: N=256 holdout содержит три заранее отобранных рамповых протокола; он не содержит парного #local15_constant контроля. Базовые числа V17C.10 получены на другом seed-set и не являются парным контролем для этого holdout.
