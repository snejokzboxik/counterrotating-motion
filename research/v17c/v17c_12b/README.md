# V17C.12B: физическая реализуемость встречного вращения

Этот каталог содержит исходную размерную параметризацию, исследование поля, воспроизводимые траекторные серии и аудиты. По уточнению научного руководителя от 20.11.2026 успехом считается любое устойчивое встречное вращение `(+−)` **или** `(−+)`; равенство их вероятностей и сосуществование обоих режимов не требуются. Основная цель — физически реализуемая конфигурация с суммарной вероятностью CR около 80% и выше, при отдельном учёте сонаправленного вращения и потерь. Полная формулировка и пересчёт итогов — в [`UPDATED_OBJECTIVE_RU.md`](UPDATED_OBJECTIVE_RU.md). Ранее завершённая фиксированная пара Al₂O₃/K1 сохраняется как отрицательный результат для той конфигурации: удержание 485/512, все удержанные пары пришли к `(−−)`.

## Окружение

Использованы Python 3.12, NumPy 2.5.3, SciPy 1.18.1, Numba 0.68.1, scikit-fem 12.0.2 и Gmsh 4.15.2. Зависимости для повторения устанавливаются из `requirements.txt`. Рабочий `.venv` локален и не включается в публикацию.

## Воспроизведение

Из каталога `research/v17c/v17c_12b/`:

```powershell
python model/physical_parameterization.py
python run_physical_screen.py --threads 11
python screen_parameter_grid.py
python model/mfs_surface_refinement.py
python model/mfs_breakdown.py
python model/fem_crosscheck.py
python physical_mixed_pair_search.py
python model/audit_mixed_pair_search.py
python physical_mixed_pair_charge_frequency_sweep.py
python model/audit_mixed_pair_charge_sweep.py
python physical_parameter_sobol_screen.py
python model/audit_physical_parameter_sobol_screen.py
python model/rank_physical_parameter_sobol_screen.py
python updated_objective_validation.py
python model/audit_updated_objective_validation.py
```

Серия `run_physical_screen.py` использует четыре замороженные Sobol-страты по 128 стартов, 15 000 RF-периодов и RK4/64. Стартовые состояния, RF-фазы, параметры, журнал каждой траектории и сводка сохраняются в отдельном каталоге результатов. Перезапуск возобновляет серию только при совпадении метаданных.

`screen_parameter_grid.py` проверяет 27 точек по амплитудам двух RF-базисов и отношению частот; в каждой точке используются 32 старта из покоя. Эта сетка предназначена для обнаружения режимов и не даёт точной оценки вероятности.

`sobol_identical_search.py` исследовал радиус Al₂O₃ 17 µm: 4096 коротких запусков завершены и независимо аудированы, встречного вращения нет. `sobol_alumina_multiradius_search.py` проверил радиусы 5–40 µm: ещё 4096 запусков, также без встречного режима. `sobol_alumina_experimental_50hz_search.py` завершил 6144 траектории для радиусов 10–15 µm, 50 Hz, экспериментальных диапазонов заряда и напряжения, rest и стартовой скорости 0.5–2 m/s. Восьми конфигурациям с лучшим удержанием затем заданы встречные начальные скорости: 128 длинных траекторий по 15 000 периодов перешли к `(++)`/`(−−)`, без встречных поздних меток. Все серии используют до 11 worker-ов; это discovery и directed-проверки, не оценки вероятностей.

`physical_mixed_pair_search.py` проверяет физически связанную пару Al₂O₃/K1 в четырёх замороженных ансамблях, всего 512 траекторий RK4/64 по 15 000 периодов, с 11 worker-ами. Результаты и независимый аудит находятся в `results/mixed_alumina_k1_candidate/`. Удержание составило 126/128, 127/128, 119/128 и 113/128; все 485 удержанных исходов классифицированы как предварительное `(−−)`, 27 потерь — радиальные. Это скрининговые ensemble-частоты для одной конфигурации, не IID-вероятности. Модельная пара использует плотность K1 по спецификации, но не является совместно измеренной парой частиц.

`physical_mixed_pair_charge_frequency_sweep.py` сравнивает две точки по тем же замороженным стартам, всего 1024 траектории с 11 worker-ами. Каждая точка содержит 512 запусков RK4/64 длиной 15 000 периодов; результаты и аудит находятся в `results/mixed_pair_charge_sweep/`. Удержание: 476/512 при 150k/75 Hz и 466/512 при 220k/110 Hz. Все удержанные пары получили предварительное `(−−)`, а 82 потери были радиальными. Парность обеспечивает сравнимость двух сценариев, но не превращает их в IID-выборку.

`physical_parameter_sobol_screen.py` сгенерировал 2048 Sobol-предложений и проверил 1024 физически связанных точки. Discovery-серия использовала по 32 старта в каждом из четырёх ансамблей, RK4/128 и 3000 периодов. После аудита результат ранжируется по сумме обеих CR-меток, без требования найти оба направления в одной конфигурации. Короткий экран дал 31 конфигурацию с любым CR; максимум — 86/128 для `phys0570`, а целевой уровень 80% не достигнут. `updated_objective_validation.py` проводит независимую проверку лидеров `phys0570`, `phys0008` и размерных отображений `candidate52`, `local15`, `refine12_sobol17` на новых стартах: 15 000 периодов, RK4/64, 128 запусков в каждом ансамбле, до 11 worker-ов и checkpoint. Это валидация пяти зафиксированных точек, не новый Sobol-поиск или локальный оптимизатор.

## Аудит и статусы

- `results/identical_alumina_screen_corrected/` — исправленная строгая серия; её `independent_audit.json` проверяет индексы, замороженные старты, геометрические контактные события и статистические границы.
- `results/identical_physical_sobol_screen_corrected/` — завершённая и независимо аудированная размерно связанная discovery-серия для a=17 µm; короткие результаты не являются вероятностями.
- `results/alumina_multiradius_sobol_screen/` — завершённая и независимо аудированная серия по восьми размерам частиц.
- `results/alumina_experimental_50hz_screen/` — завершённая и независимо аудированная 50-Hz серия с отдельными rest и injection ансамблями.
- `results/directed_counterrotation_search/` — 128 направленных длинных стартов, аудит `integrity_pass=true`; 0 встречных поздних меток, не оценка бассейнов.
- `results/physical_parameter_sobol_screen/updated_objective_ranking.json` — воспроизводимое ранжирование короткой серии по любому CR-направлению; обе ветви и потери разложены по конфигурациям и ансамблям.
- `results/updated_objective_validation/` — fresh-start сравнение двух Sobol-лидеров и трёх размерных отображений старых кандидатов; используйте только после появления `independent_audit.json` с `integrity_pass=true`.
- `results/rescaled_legacy_candidate_validation/` — новые старты для частотно пересчитанных `candidate52`, `local15`, `refine12_sobol17`; аудит прошёл, лучший текущий счёт — 437/512 (85,35%).
- `results/additional_physical_candidate_validation/` — заключительная fresh-start проверка фиксированных `phys0352/0109/0526`: 352/512, 337/512 и 323/512 строгих CR; все потери радиальные, независимый аудит прошёл. Ошибки в двух технических попытках и их исходники/хеши сохранены отдельно; 128 вызовов из второй попытки были повторены и не включены в сохранённые trajectory-строки.
- `results/long_horizon_refine12_validation/` и `results/long_horizon_refine12_240k_validation/` — 32 выбранных CR-старта сохранили встречный знак и удержание на 120k и 240k периодах; на длинном горизонте каждый совершил более 100 оборотов. Это условная проверка продолжительности режима, не новая оценка размера бассейна.
- `results/rescaled_legacy_candidate_validation/mfs_field_audit.json` и `fem_field_audit.json` — независимый MFS/FEM cross-check поля; finer FEM mesh даёт 8.809 MV/m RF-only против 8.898 MV/m MFS у `refine12_sobol17`.
- `results/numerical_convergence_refine12/` — RK4/64, 96 и 128 шагов плюс DOP853, на одном представительном старте; audit проверяет сопоставление поздних оборотов и классификации.
- `results/physical_parameter_sobol_screen/trajectories.jsonl.gz` — lossless-архив всех 131 072 строк. Аудит и ранжировщик читают gzip напрямую. Для возобновления Sobol-runner сначала восстановите checkpoint: `python model/archive_physical_parameter_sobol_screen.py --restore`; после повторного завершения запакуйте его с `--remove-raw`.
- `results/identical_alumina_screen/` и `results/symmetric_parameter_grid/` — сохранённые прежние журналы, помеченные `INVALIDATED_RU.md`; их нельзя использовать как валидную статистику.
- `V17C7_V17C8_REPRODUCTION_RU.md` документирует, почему исходные конфигурации V17C.7/.8 пока нельзя независимо воспроизвести.
- FEM-сверка относится только к поперечному 2D сечению бесконечных электродов; она не моделирует концы, корону или газовый пробой.

Актуальный критерий — любое устойчивое встречное вращение `(+−)` **или** `(−+)`; баланс ветвей не требуется. Строгая fresh-start частота частотно пересчитанного `refine12_sobol17` — 437/512 (85,35%), но вторая частица имеет диаметр 214 µm, не подтверждённый приведёнными диапазонами K1; лучшая точка среди кандидатов в опубликованных размерных диапазонах (`phys0570`) даёт 368/512 (71,88%). Все результаты, параметры и ограничения MFS/FEM см. `UPDATED_OBJECTIVE_RU.md` и `REPORT_RU.md`. Длинная 240k-проверка дала более 100 оборотов на 32 условно выбранных CR-стартах, но не является новой оценкой бассейна. Физически реализуемая ловушка с подтверждённым запасом до пробоя не установлена.

## Физические определения

Полный набор формул и единиц приведён в `PHYSICAL_PARAMETERIZATION_RU.md`. В частности, `U1` и `U2` — амплитуды напряжения на электродах; амплитуды ведущих гармоник поля включают отдельные коэффициенты MFS `h₂` и `h₋₄`. Параметры `m_i`, `q_i`, `a_i`, `λ_i`, `C`, частоты, DC-квадруполь и вязкость взаимосвязаны и не сканируются независимо.
