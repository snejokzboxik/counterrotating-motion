# Статус набора: не использовать как физическую статистику

Этот набор сохранён для аудита, но не считается валидным результатом V17C.12B.

После серии была обнаружена ошибка в `model/basin_scan.py`: контакт частиц и стенки проверялся на промежуточных пробных состояниях RK4. Эти состояния — внутренние оценки производных, а не точки численной траектории; такой критерий мог преждевременно прервать отдельные запуски. Проверки также обновляли минимум межчастичного расстояния по этим пробным состояниям. Кроме того, начальные флаги контакта после их вычисления сбрасывались.

Исправленная реализация проверяет начальное состояние, сегмент между двумя принятыми RK4-узлами для контакта частиц и принятые концы шага для контакта со стенками. Минимум расстояния берётся по тому же отрезку. Исправленные серии сохраняются в отдельных каталогах `identical_alumina_screen_corrected` и `symmetric_parameter_grid_corrected`.

Числа в `summary.json` и строки `trajectories.jsonl` оставлены неизменными как доказательство выполненного запуска. Их можно использовать только для диагностики ошибки, не для сравнения физических вероятностей и не для публикации выводов.
