# Полуаналитический критерий противоположных вращательных ветвей

Для одиночной частицы с \(\alpha=Q/\mu>0\), линейным сопротивлением и двумя независимыми ведущими гармониками \((n_1,\sigma_1=+1,\nu_1=1,A)\), \((n_2,\sigma_2=-1,\nu_2=\nu,B)\) зададим
\[
K_{1}=\frac{\alpha^2n_1^2(n_1-1)A^2}{1+\lambda^2},\qquad
K_{2}=\frac{\alpha^2n_2^2(n_2-1)B^2}{\nu^2+\lambda^2}.
\]
При \(\rho>0\) баланс медленного тангенциального ускорения даёт
\[
\bar\omega(\rho)=
\frac{K_1}{\nu_1}\rho^{2n_1-4}
-\frac{K_2}{\nu_2}\rho^{2n_2-4}.
\tag{1}
\]
Радиальный баланс в DC-квадруполе:
\[
G(\rho)=\bar\omega(\rho)^2+\alpha\beta
-K_1\rho^{2n_1-4}-K_2\rho^{2n_2-4}=0.
\tag{2}
\]
Это конечная система алгебраических уравнений для медленных круговых решений. Условие \(\bar\omega_1\bar\omega_2<0\) проверяется для двух видов с разными \(\alpha_i,\lambda_i\). Корни дополнительно ограничиваются физической апертурой и конечными размерами.

Для \(n_1=2,n_2=4\):
\[
\bar\omega_i=K_{1i}-\frac{K_{2i}}{\nu}\rho^4,\qquad
G_i=\bar\omega_i^2+\alpha_i\beta-K_{1i}-K_{2i}\rho^4.
\tag{3}
\]
Критический радиус нулевого среднего drift-момента \(\rho_*=(\nu K_1/K_2)^{1/4}\) — только граница смены знака torque function; он не обязан совпадать с допустимой радиальной ветвью, а устойчивость требует отдельной проверки.

## Один воспроизводимый local15 пример

Зафиксированы параметры local15 из V17C.13, leading harmonics only, Coulomb \(=0\), полный MFS-спектр отброшен:
\(A=0.03716194907442204\), \(B=0.1626938199343468\), \(\nu=3.1118029452860356\), \(\beta=0.017273303124515367\), \(Q_2=3.1179673274978996\), \(\mu_2=9.136629008688033\), \(\lambda_1=0.20975541409005094\), \(\lambda_2=0.12617311138613094\).

Алгебраические устойчивые корни: вид 1 \(\rho=0.5503691530\), \(\bar\omega=+0.0014400542\); вид 2 \(\rho=0.7663818562\), \(\bar\omega=-0.0010579232\). Это аналитическое предсказание знаков без подгонки. Оно не является полной 24-электродной моделью, поскольку не учитывает высшие MFS-моды, Coulomb и RF-микродвижение за пределами ведущего усреднения.

Для сравнения V17C.13 сообщил из полного восьмигармонического N=6 расчёта local15 на 120 000 post-load периодах RK4/96 \(r/R=0.5480284,0.7660739\) и групповые частоты \(+150.133538,-99.955551\) Hz при \(f_1=100\) kHz. После нормировки частоты равны \(+0.0015013354,-0.0009995555\). Неподогнанные относительные ошибки leading-only предсказания: радиусы \(+0.427\%\), \(+0.040\%\); частоты \(-4.08\%\), \(+5.84\%\) по signed convention. Это cross-model сопоставление, не независимый single-particle benchmark: численный ориентир — Coulomb-coupled 3+3 crystal с protocol #505. Источник: V17C.13 commit 5438b1cdd79c47abab45c6cbaf99c6daec9fbb60.

Раздел V17C.14 не переоптимизирует параметры и не утверждает, что условие противоположных знаков достаточно для конечного горизонта удержания.
