## Local15 и протоколы

Точные поля и параметры: `local15_n6_parameters.json`, источник — V17C.11 `local15_parameters.json`. Порядок `p`: `[A,B,nu,beta,s=m1/m2,C_eff,lambda1,lambda2]`. Протоколы `constant`, #505, #353 и #292 читаются напрямую из опубликованных V17C.11 JSON через `load_protocols()`; фазы RF не сбрасываются. #505 является только одним из контрольных вариантов, не считается заранее оптимальным для N=6.

Нормировка межгрупповой Coulomb основывается на `C_eff=q1*q2/(4π ε m1 R³ Ω1²)`. Для local15: `C11=C/qratio=3.0350291055e-6`, `C12=C=9.4631215891e-6`, `C22=C*qratio=2.9505703930800456e-5`; после деления на массу группы 2 коэффициенты ускорения `C12,2=s*C=1.0357344684e-6` и `C22,2=s*C*qratio=3.2293862324e-6`.

## Следующий шаг P1

Запустить только небольшие симметричные поисковые тесты 3+3 из покоя, затем проверить каждый найденный режим на возмущённых начальных состояниях. Начальная сетка: кольца `r1≈0.45R`, `r2≈0.63R`, углы `0,120,240°` внутри каждого кольца, относительный угол между кольцами варьировать. Проверить z-сценарии общих плоскостей и смещения `0, ±0.1R, ±0.25R`. Сравнить local15 constant, #505, #353, #292. Сохранять все неудачи.

Для подтверждения кристалла анализировать каждую частицу: развёрнутый угол, частоту, r, z; каждую тройку: разброс частот, циклические интервалы, относительные фазы, все внутренние расстояния и `Psi3`. Одна только противоположность средних знаков — только `COUNTERROTATING_UNORDERED`, не успех кристаллизации. Успех 3+3 должен иметь две противоположные тройки с ограниченными относительными фазами, `Psi3` и дистанциями.
