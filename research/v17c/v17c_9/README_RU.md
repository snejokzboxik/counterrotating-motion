# V17C.9 — воспроизводимый поиск бассейнов встречного вращения

Работа разделена на контрольные этапы. Начальная задача P0 оценивает бассейны исходной конфигурации V17C.5 для трёх раздельно публикуемых ансамблей: старт из покоя, слабые скорости и широкая выборка. Классы исходов и знаменатель фиксируются до сравнения с оптимизированными параметрами. Случаи без достаточного числа оборотов не засчитываются как CR; они остаются неопределёнными и сохраняются для продления.

## Исходные данные

- Номинальная модель и коэффициенты MFS: `../v17c_5/input/config.json`.
- Проверенный интегратор и подробная номинальная траектория: `../v17c_5/`.
- Архивы V17C.6–V17C.8 локально находятся в `input/`; они исключены из git из-за объёма, но перечислены с SHA-256 в `input/SOURCES.json`.
- Сам текст задания сохранён в `input/V17C_9_request_RU.md`.

Контрольные точки и запуски сохраняются отдельно по ансамблям. Повторный запуск сканера пропускает уже записанные идентификаторы. Неопределённые и потерянные случаи остаются в исходном знаменателе `N_total`.

## Текущий gate

1. Проверить контрольные суммы источников и воспроизвести модель.
2. Измерить скорость/память сканера на малом пилоте.
3. Запустить первичный статистический скрининг исходной конфигурации.
4. Продлевать случаи с возможным встречным вращением независимым численным контролем.
5. Только затем переходить к P1 и более дорогим расширениям.

Не следует переносить выводы V17C.6–V17C.8 на исходное поле V17C.5: там менялись демпфирование/DC-модель и горизонты были недостаточны для заявленной строгой метрики.
