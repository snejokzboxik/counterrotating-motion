# Численная проверка и воспроизводимость V17C.22

## Источники и неизменность

- Ветка источника: `research/v17c21b-m3-bifurcation-diagrams`.
- Исходный и опубликованный SHA: `894c6896ce5927371708037ffa4a4021189d2b54`.
- Новая ветка создана от этого SHA.
- Использованы V20A conditional/extended QR, perturbation и section records; V20B candidate registry, 240k trajectory archive; V21.1 M3 root и slow-flow Jacobian.
- Номинальный параметр-вектор не менялся: `A,B,nu,beta,s,C,lambda1,lambda2 = [0.03492413282400757, 0.15631667332941065, 3.2196773638017477, 0.015388559140477825, 0.10963763906505944, 9.747265456858355e-6, 0.24452307123064748, 0.17736598731050257]`; `qratio=3.4490536225028334`.

## Выполненные проверки

1. `audit_stability_evidence.py` прочитал архивные источники, проверил длительные QR отношения сумма/дивергенция, строгую JSON сериализацию новых агрегатов и сформировал новые таблицы/рисунки.
2. `test_full_rf_jacobian.py` — 12 независимых состояний, аналитический full RF Jacobian против центральных разностей собственного NumPy RHS. Максимальная масштабированная ошибка (5.97\cdot10^{-11}); тест проходит при пороге (2\cdot10^{-7}).
3. `full_rf_short_perturbation.py` — две пакетные DOP853 интеграции, каждый пакет содержит пять независимых 12D trajectories. Правая часть — векторизованный NumPy вариант опубликованного `v17c_20b/code/dop853_independent.py`; она не использует Numba RK4. Обе RF-фазы точно перенесены от архивных периодов 238000 и 240000. Успешно завершено по 300 RF1-периодов с `rtol=1e-9`, `atol=1e-11`, `max_step=2π/96`.
4. Все новые JSON используют `allow_nan=False`; результат аудита повторно прочитан стандартным `json.loads`.
5. Графики выстроены из сохранённых CSV/NPZ/JSON; PNG сохранены с 600 dpi, плюс PDF и SVG.

## Ограничения проверки

- На компьютере отсутствует Numba, и сетевой установщик недоступен через системный proxy. Поэтому QR не пересчитывался заново, а использованы опубликованные и сохранённые V20A спектры. Новые DOP853 короткие проверки не заменяют длинную RK4/QR сходимость.
- Новый DOP853 прогон не был сопоставлен точка-в-точку с компилируемым V20B RK4 RHS; он использует отдельный портированный путь DOP853. Проверка Jacobian finite differences подтверждает согласованность производной с этим RHS, но сама по себе не является независимой проверкой всей правой части.
- Номинальные 64/96 RK4 refinement и независимые 15000-периодные полные RF проверки уже находятся в V21.2; они не повторялись.
- Новый DOP853 горизонт составляет 300 периодов, недостаточный для оценки медленной частоты и для 10–30 полных оборотов.
- Парный зазор в коротком прогоне оценивался по сохранённым отсчётам с интервалом один RF1-период; непрерывное event detection столкновения и конечная геометрия стенок в этой проверке не моделировались.
- Прямая проверка полного неадиабатического Fourier-замыкания M3+ не выполнена. Результаты M3+ в данном коммите — вывод уравнений, не численно валидированный slow-flow.
- Манifold/торус размерность не реконструирована и нормальное подпространство не вычислялось.

```powershell
python research/v17c/v17c_22/code/full_rf_short_perturbation.py
python research/v17c/v17c_22/code/audit_stability_evidence.py
```

Полные входные SHA-256, численные сводки и параметры сохранены в `results/stability_evidence_audit.json`, `results/short_dop853_perturbation_summary.json` и `MANIFEST.json`.
