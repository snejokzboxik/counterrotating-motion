# Предварительный линейно-стоксовский пилот

Эти файлы сохранены как аудит чувствительности модели, а не как часть основного скана V17C.17.

В первом пилоте использовалось линейное сопротивление Стокса без нелинейной поправки по числу Рейнольдса. Все десять значений связи для `scaled_refine12_sobol17_f50hz` потеряли удержание в пределах первого RF-периода; точки `phys0570` при `sC=0, 0.1, 0.25, 0.5, 0.75` завершились, после чего пилот остановили. Это не воспроизводило опубликованные V17C.12B траектории, для которых был включён Schiller–Naumann self-drag. Поэтому результаты пилота не объединялись с главными рядами и не интерпретировались как опровержение встречного режима.

Основной скан после этого пересчитан с поправкой Cunningham индивидуально для каждой частицы `lambda_i=lambda_Stokes,i/Cc_i`, прежней Schiller–Naumann-функцией `1+0.15 Re^0.687` и выключенной межчастичной гидродинамической подвижностью. Все исходные файлы пилота оставлены без изменений.

`coulomb_scan.jsonl` — незавершённые/остановленные строки пилота. NPZ в `trajectories/` содержат его контрольные траектории, включая нулевые по длине файлы для немедленных потерь.
