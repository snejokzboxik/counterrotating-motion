# SESSION HANDOFF — V17C.21

## Состояние исследования

Реализована и проверена локальная полуаналитическая модель встречного вращения `refine12_sobol17` по данным V20B. Новые результаты изолированы в `research/v17c/v17c_21/`; ветка основана на V20A `43c84bf72ce0807d244475518588770fbaf0fb69`. Старые результаты в данном checkout не редактировались.

## Главный численный результат

M3: \(r/R=(0.5550375,0.7513383)\), \(f_{orb}=(+0.0547220,-0.0487398)\) Hz. Ошибки относительно V20B 240k RK4 эталона: радиусы −0.123%, −0.024%; частоты +0.136%, −0.590%. Модель использует полный восьмигармонический MFS RF field и тороидальную Fourier-collocation для Schiller–Naumann drag. Coulomb включён в средние совместные радиально-осевые балансы, но не в быстрый micromotion solve.

Четыре 15k независимых one-factor hold-outs сохранены: A×1.05, B×0.95, nu×1.02, beta×1.05. Полное движение сохраняет counterrotation во всех четырёх случаях. M3 рассчитана на всех четырёх точках: внешняя частотная ошибка 0.62–2.00%, внутренняя 0.03–0.39%, радиусы 0.02–0.132%. Наибольшее расхождение — внешняя частица при B×0.95, что следует учитывать как локальную границу точности.

## Научный статус

Установлено численно: усреднённый локально устойчивый M2 корень, M3 баланс сходимости средних величин по сетке при большинстве режимов, и конечновременное долгоживущее встречное движение в исходных данных и hold-outs. Не доказаны: аттрактор полной системы, глобальный basin, существование устойчивого двумерного тора, экспериментальная реализуемость. Поле поперечного MFS соответствует бесконечно длинным электродам; DC-квадруполь идеализирован, поляризация отключена. В V20B тяжесть добавлена как одинаковое ускорение обеим частицам без buoyancy correction; для низкоплотной второй сферы это отдельно ограничивает размерную интерпретацию осевого положения.

`heldout_validation.py` uses Numba-интегратор V17C.17/V12B; в этой среде Numba поставлен изолированно в `%TEMP%\v17c21_deps`, не в системное окружение. Для воспроизведения через установленный system Numba достаточно прямого `python .../heldout_validation.py`; если Numba отсутствует, потребуется установить зафиксированную версию либо использовать сохранённые NPZ/JSON.

Дополнительная проверка микродвижения — один новый парный replay длительностью 1000 RF1-периодов, 64 RK4 шага на период, с RF-фазами, перенесёнными из абсолютного времени. Его high-pass RMS совпадает с M3 на 0.00152% и 0.00376%. Удаление медленного орбитального движения задано отсечкой 0.05 циклов на период RF1; спектр конечного окна — диагностика выбранной поздней траектории.

Учёт вычислений: пять новых полных парных траекторий (4×15k hold-outs + 1×1k replay = 61k новых RF1-периодов); плюс два архивных V20B расчёта (240k nominal и 5k (C=0)), всего семь записей и 306k периодов рассмотренного горизонта. Полная пара в каждом запуске содержит обе динамические частицы. Шесть наборов параметров: nominal, (C=0), четыре hold-out. Массового сканирования не выполнялось.
