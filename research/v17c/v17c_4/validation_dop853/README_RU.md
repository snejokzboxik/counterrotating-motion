# Независимая проверка динамического ядра ADCFEB

Скрипт `independent_dop853_check.py` независимо реализует RF-градиент и правую часть 3D RF–DC уравнений. Он использует весь сохранённый комплексный MFS-спектр ADCFEB из P1 FEM/MFS-сверки и не вызывает функции `_rf_accel` или `_rhs_aug` из основной модели. Существующий RK4 запускается только для сравнения.

## Проверяемая модель

Для каждой частицы в безразмерном времени `tau`:

```text
r'' = a_RF(r,tau) + beta (x,y,-2z) + a_Coulomb - lambda v
```

RF-потенциал задан как `Re[sum_k A_k z^|k| exp(-i tau)]`, с `z^|k|` для положительных `k` и `conj(z)^|k|` для отрицательных. Ускорение — `-alpha grad(Phi_RF)`. Парная кулоновская сила направлена по вектору `r_i-r_j` и масштабируется как `chi*q_i*q_j/(m_i*|r_i-r_j|^3)`. Отношение `beta_i/alpha_i` одинаково у двух частиц, что соответствует общим напряжениям RF/DC.

DC-потенциал на единицу массы пропорционален `beta*(z^2-(x^2+y^2)/2)`. Его гессиан имеет след `-beta-beta+2beta=0`; сила `beta*(x,y,-2z)` удерживает положительный z и не даёт азимутального момента.

Полная механическая энергия, проверенная в коде:

```text
E = sum_i m_i [ |v_i|^2/2 + beta_i (z_i^2 - (x_i^2+y_i^2)/2) ]
    + chi*q_1*q_2/|r_1-r_2|
```

Для неё `dE/dtau = P_RF + P_drag`; суммарные DC- и кулоновские мощности учитываются через изменение соответствующих потенциальных энергий.

## Контрольный запуск

В контрольном двухчастичном случае на горизонте 10 периодов получено:

- максимальная ошибка RF-ускорения относительно основной функции — `6.1e-18`; относительно разностного градиента полного RF-потенциала — `5.8e-13`;
- конечная ошибка Cartesian state против DOP853: `7.12e-7` для RK4 с 64 шагами/период и `4.40e-8` для 128 шагов/период; ошибка уменьшается в `16.20` раза при удвоении шага, близко к ожидаемому порядку RK4;
- относительный энергетический остаток DOP853 после учета RF и сопротивления: `1.0e-14`;
- интегралы кулоновского момента частиц равны и противоположны с суммой `6.9e-18`;
- конечное разделение частиц положительно, модельная сингулярность не достигнута.

Это проверка знаков, нормировок и интегрирования, а не кандидат устойчивого вращения и не физическая реализация. Численные параметры, контрольные состояния и полные траектории трёх интеграторов лежат в JSON/NPZ рядом.
