# V17C, серия 4 — 3D, аксиально разделённые кулоновские группы

## Модель
Точечные положительные заряды, 3D, безразмерное время tau=Omega*t, координаты /R, массы /M0, заряды /Q0. k=.1044, f=100 kHz, R=8 mm только для иллюстрации размерности. C=Q0²/(4πε0 M0 Omega² R³), независимые относительные массы, заряды, затухания lambda_i. Трение -lambda_i (1+3/16 Re_star |v_i|)v_i, Re_star=.3; это поправка Озена к локальному сопротивлению, не межчастичный тензор Озена. Нет физической калибровки среды. Все скорости и радиусы безразмерны.

Пусть u=x+iy, z осевая координата. RF-потенциал V=k Re[u^4 A(z,tau)+eps u^8 exp(+i tau)]. mode=0: A=exp(-i tau); mode=1: A=cos(tau); mode=2: A=(1+z/d)/2 exp(-i tau)+(1-z/d)/2 exp(+i tau). В mode=2 вычислена также осевая сила -dV/dz. Это гармонический в 3D потенциал (удовлетворяет уравнению Лапласа), но не существующая 12-электродная геометрия. Необходимы независимые осевые секции/электроды; линейная зависимость амплитуды от z — математическая идеализация, вне |z|<=d возникают отрицательные веса. eps=.32945 — только отношение амплитуд FEM, фаза не валидирована.

Осевое удержание az=0: электрический DC-квадруполь Vdc=w²/2*(z²-r²/2); az=1: независимый механический/эффективный осевой потенциал энергии m_i*w²*(z²-d²)²/(8d²), не свободный электростатический потенциал; az=2: электрический гармонический двойной колодец Vdc=w²/(8d²)*(z⁴-3z²r²+3r⁴/8-2d²(z²-r²/2)). В вариантах 0,2 электрическая сила умножена на q_i/m_i. Кулоновские расстояния 3D, защита r²>=1e-24. Границы проверки r<1, |z|<1.5 условные, не реальная геометрия. Начальные конфигурации — минимизация приближённого ведущего псевдопотенциала+кулоновской и статической энергии; не точная RF-релаксация, для mode=2 начальная минимизация игнорирует z-зависимость RF. В отдельных extra минимизация выдала предупреждения при коллизионных пробных точках; все исходные состояния сохранены, выводы ограничены траекторным поиском.

## Расчёты и основные результаты
* run.py: 96 расчётов N=6, 600 RF, 48 шагов/RF. По 24 чистый RO, RO+eps=.32945, SO, mode=2. Удержаны 18,18,20,20. 11 предварительных кандидатов только mode=2 (углы >.1 или <-.1 оборота у одних и тех же частиц в каждом из трёх последних окон по 20%, min r>.015).
* confirm.py: 11 кандидатов повторены с двумя разрешениями 96,192 шагов/RF до 4000 RF, всего 22 интеграции. Все удержаны. Критерий >1 полного оборота в каждом из трёх окон у одной частицы и <-1 у другой выполняют case 35,43,59,67,83 на обоих разрешениях. На case83 все три нижние частицы ~-631 Hz, три верхние ~+631 Hz, средний радиус .30323R, z≈±.61710R, минимальная парная дистанция за весь расчёт .38154R. Все частицы одинаковые, C=.0002, w=.045, d=.45, az=2, mode=2, eps=0, lambda=.003. Дополнительные повторные расчёты для трасс case59,83,80,81,82 (192/4000, 5 интеграций). При аналогичных параметрах case80/81 (одинаковое направление поля) все частицы вращаются в одну сторону, ~629 Hz; SO case82 практически без вращения. Начальные состояния для контролей получены отдельной минимизацией, не абсолютно идентичны.
* validate.py: конечные разности полной энергии для 9 сочетаний осевых и RF-моделей, максимальная абсолютная ошибка силы 1.43e-12. Независимый DOP853 (rtol 1e-10, atol 1e-12, max_step=.35) от конечного состояния case83 на дополнительные 1000 RF дал угловые обороты [-6.3223,-6.3000,-6.3201,6.3073,6.3114,6.3123]; выборка 4 точки/RF; максимальный радиус .31901R, |z|max .62074R. Это продолжение, не отдельный начальный ансамбль.
* extra.py: 32 расчёта N=12, 800 RF, 64 шага/RF, разные массы/заряды/затухания, az=1,2, чистый RO и RO+eps=.32945. 26 удержаны, 0 кандидатов по критерию .1 оборота. 
* Всего 156 интеграций (96+22+5+1+32), включая повторы. summary.csv содержит 155 RK4 строк; DOP853 отдельно в validation.json и dop853_83.npz. Нет доказательства асимптотического аттрактора; нет подтверждения встречного вращения в исходной односекционной ловушке (104 стартовых расчёта обычных полей). Нет сравнения с сегментированным квадруполем, FEM 3D, собственных вращений тел, гидродинамической взаимной связи или доказательства новизны.

## Воспроизведение
Python 3.13, numpy, scipy, numba, matplotlib. Запуск из каталога: python run.py; python confirm.py; python extra.py; python validate.py; python summarize.py. NUMBA_NUM_THREADS=4 (по умолчанию). Входы inputs.npz и extra_inputs.npz: ys=(x,y,z,vx,vy,vz), ps=(k,C,eps,axial_mode,wz,d,chirality_mode,Re_star), ms,qs,gs; meta=(mass_ratio,charge_ratio,drag_ratio,seed). В выходах s — сумма изменений угла, радиусов, z, углового момента в 3 окнах последнего 60% времени, ct — число шагов, mi — минимальный радиус по окнам, rs=(max_r,max_abs_z,min_pair,max_Re). fin — конечное состояние, st=1 удержание. Углы вычислены вокруг общей оси z, не собственное вращение тела. trace*.npz — стробоскопические ряды через 5 RF; остальные полные шаговые траектории не сохранялись, воспроизводимы из исходных состояний и кода. При выходе статистика неполная. Проверка границы на узлах RK4, без локализации события. Данные summary.csv не заменяют сырые оконные массивы.
