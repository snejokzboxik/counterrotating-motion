# V17C: поиск встречного вращения с поправкой Озена
Двумерная динамика одинаковых точечных положительных зарядов с 3D законом Кулона, R=8 mm (для интерпретации шкалы), f=100 kHz, kappa=0.1044. lambda=gamma/Omega. Осевая координата отсутствует. Drag=-lambda(1+3/16 Re_star |v|)v, Re_star=0 либо 0.3. Re рассчитывается в безразмерных переменных. Параметры lambda, C, Re_star заданы независимо, не откалиброваны под конкретную сферу/газ. Модели mode=0 RO4, mode=1 SO4, mode=2 SQ2; eps=0.32945 добавляет Re[kappa eps z^8 exp(+i tau)] к RO4, относительная амплитуда из прежней FEM-реконструкции, комплексная фаза условно нулевая (не валидация FEM). Сравнение по равным коэффициентам, не равным напряжениям. RK4 FP64; отсечение по апертуре на узлах, кулоновская сингулярность защищена r^2>=1e-24. 
run.py: 216 сценариев, 7/12/19 частиц, 400 RF, 48 шагов/RF, 42 удержаны. relaxed.py: 162 сценария, 1000 RF, 48 шагов/RF, 145 удержаны; положения через минимизацию усредненного псевдопотенциала, 0 или противоположные заданные спины групп, RO микроскорость первого порядка. Один предварительный кандидат relaxed12 index 15. Критерий scout: одна и та же частица >0.05 оборота и другая <-0.05 оборота в каждом из трех последних окон длины 20% горизонта, min r>0.02R для этих частиц. Это слабый критерий отбора, не подтверждение вращения. confirm.py: кандидат и пять контролей при 96/1000, 96/6000, 192/6000 steps/RF и RF-периодов, 18 интеграций. Исходный кандидат не выдержал уточнения, к 6000 RF все 12 имеют +20.715..20.723 Hz по последнему 1200 RF окну (0.249 оборота). Отдельная аномалия чистого RO связана с окрестностью r=0 и исчезает при уточнении. Никакого устойчивого встречного вращения не подтверждено.
hydro.py: 48 дополнительных сценариев, 2000 RF, 96 steps/RF. hydro_model.py: первое отражение обратной Oseen mobility: drag=-lambda(1+3/16 Re)v_i + lambda sum_j (3a/(4r_ij))(I+rhat rhat^T)v_j, a/R=0.002. Это приближенный сценарный член, не полноценная нестационарная гидродинамика; многотельная обратная матрица не вычислялась. 39 удержаны, 0 кандидатов, min separation среди удержанных >=0.03756R. Не смешивать поправку Озена и гидродинамическое взаимодействие. В удержанных Oseen расчетах Re_max<0.1; в некоторых вышедших Re_max>0.1. 
NPZ: ys исходные x,y,vx,vy; p столбцы C,lambda,mode,Re_star,eps,phase[,spin]; st=1 удержаны; o[j,w,i,0] сумма непрерывных приращений угла в трех окнах последних 60%; o[...,1] сумма радиусов; o[...,2] сумма L; mi минимальный радиус по окнам; rs max радиус, min межчастичное расстояние, max Re; fin конечный state. Всего 216+162+18+48=444 интеграции, включая повторные проверки. Ни одна не устанавливает отсутствие встречных аттракторов вообще. Нет неодинаковых частиц, вращения собственных тел, истинной FEM-фазы, стенок, 3D, экспериментальной калибровки, full hydrodynamics. Запуск python run.py; python relaxed.py; python confirm.py; python hydro.py (numpy scipy numba).
