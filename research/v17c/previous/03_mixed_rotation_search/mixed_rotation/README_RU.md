# Третья серия V17C: неодинаковые кулоновские частицы

## Модель
Плоское движение положительных точечных зарядов в идеальном RO4/SO4 и RO4+контрвращающемся m=-8. kappa=0.1044, f=100 kHz, R=8 mm условно. Относительные массы m_i и заряды q_i нормированы на ненулевые M0,Q0. C=Q0²/(4πε0 M0 Ω² R³). Ускорение от внешнего поля умножается на q_i/m_i, кулоновская пара на C q_i q_j/m_i. Сопротивление -lambda_i(1+3/16 Re_star |v_i|)v_i. Re_star=0 либо 0.3. Параметры заданы независимо, физическая калибровка газа/частиц отсутствует. Положительные заряды исключают коллапс разноименных зарядов. Гидродинамическая взаимная связь в третьей серии не включена. m=-8 добавляется как Re[kappa epsilon z^8 exp(+i tau)]; epsilon=.32945 — только относительная амплитуда старой FEM-реконструкции, фаза условно нулевая; epsilon=1.2 — усиленный математический контроль. Никакой новой FEM-валидации нет. Сравнение полей по одинаковым коэффициентам, не одинаковому напряжению или RMS.

## Расчеты
- run.py: 384 scout (192 на N=7 и 12), 600 RF, RK4 FP64 48 шагов/RF, по 96 на RO, SO, RO+eps=.32945 и RO+eps=1.2. Удержаны 52,69,54,52 соответственно (227 всего). 0 кандидатов по критерию трех окон. Начальные конфигурации получены минимизацией ведущего псевдопотенциала с кулоновской энергией, без вклада m=-8 при начальной минимизации. Отдельные случайные конфигурации разных полей, сравнение чисел удержания не парное. 14 случаев с противоположными знаками в последнем окне отобраны для продолжения. 
- confirm.py: 14 случаев повторены при 96/600, 96/4000, 192/4000 (42 интеграции), все удержаны, ни одного кандидата по критерию трех окон. Критерий отбора: одна и та же частица >0.05 оборота и другая <-0.05 оборота в каждом из трех последовательных окон по 20% горизонта, min r>0.02R. Это скрининг, не доказательство асимптотики; для подтверждения встречного вращения требуются многочисленные полные обороты в каждом окне и стабильность относительно увеличения времени/точности.
- targeted.py: 36 интеграций, 2000 RF, 96 шагов/RF из конечного состояния кандидата confirm_n12_192_4000.npz idx=0. Отношение затухания двух внутренних частиц к внешним 0.1,1,10; epsilon=0,.32945,1.2; Re_star=0,.3; дополнительный внутренний спин 0 или -.015. Все удержаны, 0 кандидатов. В точке 15 внутренние частицы имеют в последнем окне примерно -0.22 Hz, что соответствует менее 0.001 оборота и не является обращением. 
- Всего 462 интеграции, из них 305 с удержанием всех частиц, включая повторные/продолженные расчеты.

## Дифференциальное вращение
В confirm_n12_192_4000.npz idx=0 и idx=2 (исходные scout_n12_112.npz строки 6 и 15), epsilon=1.2, C=5e-5, одинаковые массы и заряды, разные индивидуальные коэффициенты затухания (ratio 0.1 либо 10). Во внешней группе 10 частиц ~787–791 Hz при среднем r≈0.343R; две внутренние имеют |f|<0.03 Hz, r≈0.125R. При 96 и 192 шагах/RF частоты и радиусы практически совпадают для этих двух исходных состояний. Это ограниченный по времени режим, не доказательство устойчивого аттрактора. На чистом RO после переноса этого состояния и изменения трения (targeted.npz) разделение скоростей сохраняется до 2000 RF; строгая сходимость этого переноса не проверена. Для другого чистого RO старта confirm_n12 row 1 топология оболочек меняется при уточнении шага (96/192) — его нельзя считать подтвержденным. Встречное вращение не установлено.

## Файлы и ограничения
NPZ: ys,fin — начальные и конечные x,y,vx,vy; m,q,g — относительные массы/заряды/безразмерное трение; p в scout/confirm: C,lambda_base,mode,Re_star,epsilon,phase,spin,mass_ratio,charge_ratio,drag_ratio. В targeted p: C,epsilon,drag_ratio,Re_star,added_spin. mode=0 RO,1 SO. o[...,0] сумма приращений угла (рад), o[...,1] сумма радиусов, o[...,2] сумма удельных L по трем окнам последних 60%; mi min радиуса по окнам; rs max радиус, min расстояние пары, max Re. st=1 удержано. При выходе оконные данные неполны. Учет выхода и min пары на узлах, без event refinement; кулоновская сингулярность защищена r²>=1e-24. Угол вокруг оси, не вокруг COM. Отсутствуют полные траектории всех шагов, доступны исходники, параметры, конечные состояния и оконная диагностика для воспроизведения. Нет 3D, собственных вращений тел, полного гидродинамического тензора, экспериментальных параметров, фаз FEM, Floquet/доказательства аттрактора. При малых радиусах и незавершенных оборотах не интерпретировать численный знак средней частоты как вращение.

Запуск (Python, NumPy, SciPy, Numba): python run.py; python confirm.py; python targeted.py; python summary.py. summary.csv — одна строка на интеграцию. Частоты соответствуют f_RF=100 kHz. Для повторов статистика не независима.
