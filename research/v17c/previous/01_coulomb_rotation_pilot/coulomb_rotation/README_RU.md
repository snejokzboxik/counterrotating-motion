# Поисковые расчёты кулоновского коллектива
Чистый идеальный RO4/SO4, одинаковые точечные заряды, плоская динамика, трёхмерный закон Кулона 1/r, линейное лабораторное сопротивление. kappa=0.1044, f=100 kHz, единичная апертура; начальные положения — возмущённое кольцо, скорости и RF-фаза случайные, один фиксированный seed генератора 12456. RO/SO используют одинаковые старты и одинаковый коэффициент потенциала, не одинаковый RMS поля. C = q²/(4πε0 M Ω² R³). RK4 FP64 48 шагов/RF на 400 RF, 96 шагов/RF на 3000 RF для 26 выбранных случаев. На каждом шаге вычисляется приращение полярных углов относительно оси и общего центра масс. Критерий mixed: одна и та же положительная и другая отрицательная частица с |средней частотой| >1 Hz в каждом из трёх последовательных окон, охватывающих последние 60% расчёта. Это конечновременная поисковая метка, не доказательство асимптотики. Угол около нулевого радиуса не определён устойчиво; такие данные не интерпретировать как вращение. Частоты ниже 1 Hz этим критерием не разрешаются, горизонты слишком малы для медленной динамики. Выход при r>=1 на узлах времени; нет event refinement. Нет 3D, конечных тел, FEM, квадрупольного контроля или доказательства устойчивости. Большие C — сценарные, не калиброванные на конкретный объект. Контрольное удвоение шага одновременно меняет горизонт, не является изолированным тестом сходимости. Код содержит защитный нижний предел r²=1e-24; проверять минимальные межчастичные расстояния перед интерпретацией. Сырые NPZ включают исходные и конечные состояния, суммарные приращения углов и минимальные радиусы; summary.csv содержит вычисленные частоты. Запуск: python pilot.py; python confirm.py (numpy, numba, scipy).
