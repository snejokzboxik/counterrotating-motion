# Научные утверждения и уровень подтверждения

| Утверждение | Уровень | Подтверждение / предел |
|---|---|---|
| Безразмерная сила пары (i\leftarrow j) пропорциональна (\kappa Q_iQ_j/\mu_i) | Точное тождество выбранной модели | Вывод масштабирования и тест массы/парного действия |
| Энергия кольца и осевой Laplacian заданы конечными суммами | Точное для точечных одинаковых зарядов на правильном кольце | Сравнение прямых сумм/Fourier формул N=2…32 |
| Leading Local15 сохраняет оба знака вращения | Численное наблюдение для фиксированной панели/параметров | 22 retained парных старта из 24; deterministic panel, не вероятность |
| Leading Local15 предсказывает радиусы с ошибкой <0.1% | Численное сравнение | Среднее позднего окна; точная модель идеальных k=2/−4 мод |
| Leading частота вида 1 точна | Не поддерживается | Ошибка модуля около 8.4%; требует поправки/разбора |
| Moving-orbit матричная поправка улучшает прогноз | Локальная формула алгебраически проверена; на одной frozen Local15 панели kinematic-only частично улучшает вид 1 и ухудшает вид 2; full response ухудшает частоту вида 1 | Не заявлять универсальное улучшение; требуется параметрическая карта и exact-RF вариационная проверка |
| Leading predicted sign is valid near \(\nu=2.25\) | Прямо опровергнуто для exact ideal two-mode Local15 at 15k | Stable reduced root has \(\omega<0\), while all 21 retained frozen-panel starts have \(\omega>0\); around \(\nu=2.23125\) signs mix and one late-window sign flips, so no unique asymptotic boundary is established |
| (C/C_0=3.0787336) — универсальный коллективный порог | Не поддерживается | Условный порог старой редуцированной модели; прямой scan не выполнен |
| Local15 имеет глобальную высокую вероятность захвата | Не исследовано | Фиксированная панель не даёт capture probability |
| Точная RF условная механическая устойчивость доказана для Local15 | Не поддерживается: по одному старту на вид QR до 15k, один показатель почти нейтрален и остаётся положительным конечновременно | Не выводить асимптотическую устойчивость; нужны более длинный горизонт, несколько стартов и фазовые направления |
| Исправление Cunningham не изменило исходы на контрольной Local15 панели | Численное парное наблюдение для одной идеальной модели | 96 траекторий, по 24 старта/вид/конвенцию, 3000 периодов; retained состояния и знаки совпали; историческая физическая V17C.12B панель не пересчитывалась |
| Конечная физическая ловушка безопасна по электрической прочности | Не следует из этих данных | Требуется геометрический MFS/FEM breakdown анализ |

Полная N-body нелинейная устойчивость и вероятность формирования — разные вопросы; малые N проверки не являются доказательством для всех N.
