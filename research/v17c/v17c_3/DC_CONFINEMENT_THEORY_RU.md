# DC-удержание и RF-псевдопотенциал

## Лаплас и сила DC

Для

`Φ_DC = V_DC/R² · (z² − (x²+y²)/2)`

получаем

`∂²Φ/∂x² = −V_DC/R²`, `∂²Φ/∂y² = −V_DC/R²`, `∂²Φ/∂z² = +2V_DC/R²`, поэтому `∇²Φ_DC=0`. Для положительного заряда `−(q/m)∇Φ_DC` после масштабирования даёт ровно `β(x,y,−2z)`. При `β>0` движение по `z` гармонически удерживается с малой амплитудой частотой `√(2β)Ω`, а поперечное DC-поле дефокусирует: `a_r=+βr`. Его прямой момент равен `x a_y−y a_x=0` тождественно.

DC-потенциал не питает установившееся вращение. Для ограниченной траектории средняя работа статического поля за длинный интервал стремится к нулю, поскольку работа равна минусу изменению его потенциальной энергии.

## Вывод кольцевого баланса

Пусть комплексные декартовы фазоры RF-ускорения равны `f̂_x,f̂_y`, а линейный коэффициент трения в единицах `Ω` равен `λ`. Для каждой компоненты микродвижение удовлетворяет

`δ¨ + λδ˙ = Re[f̂ exp(−iτ)]`, `δ̂ = f̂/(−1−iλ)`.

Усреднение второго порядка даёт псевдопотенциал на единицу массы

`U_RF = (|f̂_x|²+|f̂_y|²)/[4(1+λ²)]`.

У одной круговой гармоники порядка `n=|k|` сумма квадратов декартовых фазоров равна `2 n² α²|c_k|²r^(2n−2)`, где `c_k=A_k/|A_m|`. Следовательно,

`U_RF,k = n² α²|c_k|² r^(2n−2)/[2(1+λ²)]`,

а средняя направленная внутрь RF-сила имеет модуль `n²(n−1)α²|c_k|²r^(2n−3)/(1+λ²)`. Для осесимметрично усреднённого спектра

`β_eq(r) = α²/(1+λ²) · Σ_k n²(n−1)|c_k|² r^(2n−4) − ω²`.

Последний член — поправка центростремительного ускорения для орбиты с `dθ/dτ=ω`; формула V17C.3 без трения и конечной скорости центра получается при `λ→0`, `ω→0`. Для одной пары `+m,−n` это даёт заданное в постановке условие, а при `m=2,n=4`: `β/(4α²)=1+12ρ²r⁴`.

## Полный спектр и ограничения усреднения

В расчётах использован полный комплексный MFS-спектр. В псевдопотенциале складываются сначала комплексные векторы поля, затем их квадраты: гармоники одной поляризации создают угловые перекрёстные члены. Поэтому равенство радиально усреднённой формулы не гарантирует локальный минимум при каждом азимуте. Полный псевдопотенциал построен численно и его стационарные точки проверялись по двум собственным значениям гессиана.

Уменьшение `β` или изменение `q/m` может сдвинуть средний радиус; оно не убирает дискретную угловую рябь. В G1 внутренний устойчивый минимум находится около `0,478R` при среднем прогнозе `0,40R` и фиксирует азимут. Для выбранных внешних параметров G2/G3/G5 не найдено устойчивых внутренних минимумов полного 2D псевдопотенциала; прямые интегрирования подтверждают быстрый выход из апертуры.

Малое микродвижение, медленный направляющий центр, отсутствие резонансов и слабая диссипация нужны для этой оценки. При заметном микродвижении или угловом захвате решает только полная RF-динамика; знак корня усреднённого момента не является доказательством вращающейся орбиты.
