# Численная проверка V12 — промежуточный результат

## Проверенная реализация

В `src/three_phase_trap/dimensionless_dynamics_v12.py` реализовано полное RF-уравнение в переменных `rho=r/R` и `tau=Omega*t` для комплексных FEM-гармоник потенциала. Сила получается как градиент реального гармонического потенциала; усреднение здесь не используется. Первый выход локализуется отдельным радиальным событием. Внутренние шаги решателя, оказавшиеся снаружи апертуры, проецируются на границу только при запросе поля, чтобы не экстраполировать N48-поле за проверенный диск.

Прогнаны восемь тестов уравнения и integrator path: конечные разности для комплексного градиента; физическая размерность и преобразование `Lambda`; правильная сумма обеих RF-квадратур в псевдопотенциале бегущего поля; сохранение интеграла Якоби чистого бегущего мультиполя; зеркальная связь двух направлений вращения; продолжение с сохранением RF-фазы; локализация первого пересечения; безопасный запрос поля на пробном шаге у границы. **8/8 пройдено.** Затем полный репозиторный набор завершился как **130 passed**; после добавления интервалов по независимым Sobol-репликам два целевых теста повторно прошли (**2/2**).

## Сверка с ранее рассчитанными FEM-траекториями

Новые безразмерные интеграции сравнивались с уже сохранёнными таблицами V11; физические SI-траектории и FEM-решения не пересчитывались.

|---|---|---:|---|

| V11: `(3.75, -6.00) mm`, `v0=0`, фаза 0° | h35 и h50; A/B/C | 6 | 6/6 статусов совпали с V11 N48; C сравнен также с независимой прямой P4-траекторией |
| V12 baseline Sobol `r00_000000`, ненулевая скорость, фаза 0° | native P4 h35/h50 против baseline N48 h50; A/B/C | 6 native P4 + 3 уже рассчитанные N48 | Все P4 h35/h50 классификации совпали между сетками и с N48 h50; расхождения времени выхода A/B на h50 не превышают `2.46×10^-6 RF`; C удержана до 1000 RF |

Для противофазной C на этом старте прямая P4 FEM дала выход при `25.5693877230 RF` (h35) и `25.5692927133 RF` (h50). Безразмерный интегратор на соответствующих P4-производных N48 реконструкциях дал разность относительно прямой P4 соответственно `+1.97×10^-5 RF` и `+1.93×10^-5 RF`. Это сравнение одного раннего выхода, а не оценка общей точности на поздних границах.

Для независимой 4D-точки `r00_000000` baseline Sobol-классификации повторены непосредственным нативным P4 интегратором на h35/h50. A вышла при `10.8735440444/10.8737774714 RF`, B — при `11.2838570720/11.2840935168 RF`; C осталась внутри апертуры до 1000 RF на обеих сетках. Уже рассчитанный N48 h50 дал `10.8737761137 RF` для A и `11.2840959701 RF` для B, те же классификации, что и P4. Новых A₄ состояний не добавлено. Машиночитаемая сводка — `validation/native_p4_baseline_r00_000000/native_p4_baseline_comparison.csv/.json`; её создаёт `scripts/analyze_v12_native_p4_baseline.py`.

Дополнительно выполнен инженерный запуск 30 коротких 100-периодных пар на коэффициентах A/B/C для h35/h50: новые dimensionless интеграции сопоставлены с физическим SI-интегратором на тех же состояниях; статусы совпали, наибольшая норма разности конечного безразмерного состояния была `1.30×10^-12`. Это короткий preflight и не считается отдельной выборкой результатов удержания.

## Пилот параллельного расчёта

Для проверки очереди, парного дизайна и формата checkpoint завершено 96 тестовых траекторий: 32 одинаковых Sobol-старта на A/B/C h50, горизонт 5 RF-периодов. Задача намеренно помечена как тест пропускной способности; её исходы и оценки объёма не включены в физические выводы. Чекпоинт хранит безразмерное состояние, достигнутый период, статус и хеш конфигурации; продолжение сохраняет абсолютную RF-фазу.

Доступно 12 логических CPU и около 16 GiB памяти, измеренных в текущей среде. По умолчанию очереди резервируют два CPU, используют не более восьми workers и отключают дополнительные потоки BLAS/OpenMP. Массовая очередь равнопикового 4D-ансамбля уже запущена на 8 workers; ранний фактический темп уточняется в `INTERIM_PROGRESS_RU.md`.

## Что эти проверки не подтверждают

- Равенство исходов на нескольких граничных стартах не заменяет сравнение всего ансамбля на h35/h50.
- N48 — гармоническая аппроксимация P4-поля; проверка C в этой таблице покрывает один контрольный старт, а не всю четырёхмерную область.
- Межсеточная смена статуса остаётся признаком пространственной неопределённости и должна быть исключена из детальных граничных утверждений.
- Максимальный радиус, записанный массовым интегратором, является максимумом плотной выборки траектории, а не математически сертифицированным супремумом.
- До завершения QMC-сходимости и широких parameter scans численные значения аксептанса отсутствуют.

Исходные контрольные таблицы находятся рядом с этим файлом в `validation/`; повторяемый запуск V11 replay — `scripts/validate_v12_against_v11.py`, а повторяемая FEM-проверка C — `scripts/validate_v12_native_p4_controls.py`.
