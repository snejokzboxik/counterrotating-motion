# V12: последовательное продолжение траекторий

Продолжение к горизонту `N₂` читает сохранённое состояние из предыдущего расчёта до `N₁` и запускает интегратор с абсолютной RF-фазой в `N₁`. Периоды `0…N₁` повторно не интегрируются. Уже вышедшие частицы копируются как поглощённые выходы: их класс не может вернуться к удержанию.

Утилита `scripts/continue_acceptance_v12.py` требует явный файл `sample_id`, поэтому долгий расчёт ограничен заранее выбранной репрезентативной выборкой. Для оценки общего `S(N)` выбрана outcome-blind схема: простая случайная выборка без возвращения по 16 стартов из каждой из четырёх Sobol-реплик (64 из 1024 точек). Выбор использует только таблицы начальных состояний, а не исходы; одна и та же выборка применяется к FEM A/B/C при h50 и масштабах 0.5/1/2. На последующих горизонтах каждый выбранный старт представляет `256/16=16` точек соответствующей реплики. Оценка использует эти обратные вероятности включения и делит взвешенную сумму на исходный размер 4×256; эквивалентно — среднее четырёх репличных долей по 16 выбранным точкам. Наборы, специально обогащённые границами или длинными радиальными экскурсиями, анализируются отдельно и не добавляются без весов в `S(N)`. Состав и seed записаны в `validation/long_time_selection_v12.csv`, `.txt` и `.manifest.json` до чтения итоговых статусов. Можно последовательно продолжать из run `N=1000` к `3000`, затем из `3000` к `10000` и далее; каждая стадия сохраняется отдельно и может быть возобновлена. Для каждого состояния остаются атомарные checkpoint-файлы, абсолютное время выхода, максимум радиуса, число вызовов RHS и статус `numerical_error`.

Проверка интерфейса продолжения: уже рассчитанная тестовая траектория `N=1` была продолжена до `N=2`; новый run завершился без ошибок. Это smoke-проверка маршрута checkpoint, не физический результат V12. Полная проверка длительных горизонтов будет выполнена на фиксированной выборке после получения широких карт конечновременного аксептанса.

Утилита продолжения доработана для настоящей цепочки N=1000→3000→10000→…: каждый этап сохраняет ссылку на исходную таблицу стартов, а следующий этап читает состояние из предыдущих checkpoints и абсолютную фазу — без возврата к N=1000. Для папок продолжений, созданных старой версией без явной ссылки на таблицу стартов, предусмотрен проход по `source_run` к исходному run. Два теста цепочки прошли; длинные физические интеграции этим изменением не запускались.
