# Аналитические результаты и границы применимости

## Точные утверждения для одиночного бегущего мультиполя

Для произвольного безразмерного потенциала `F(rho,tau)` гамильтониан равен `H=|rho'|^2/2 + Lambda F`, и `dH/dtau = Lambda dF/dtau`. Лабораторная энергия поэтому в общем случае не сохраняется. Для потенциала `Phi=U c_m rho^m cos(m theta - s tau + phi0)`, где целое `m>=1` и `s=±1`, безразмерная связь равна `kappa_m=q U c_m/(M Omega^2 R^2)`. Рисунок вращается с `omega_f=s/m` в единицах `Omega`. Сохраняется интеграл

`J = H - (s/m) ell_z`,

где `H=|u|²/2 + kappa_m rho^m cos(m theta-s tau+phi0)` и `ell_z=rho_x u_y-rho_y u_x`. Во вращающейся системе он равен `|xi'|²/2 + kappa_m xi^m cos(m alpha) - xi²/(2m²)`.

Точка доступна тогда и только тогда, когда `J - V_eff >= 0`; при равенстве начальная скорость в сопутствующей системе равна нулю. Если связная компонента множества `V_eff<=J`, содержащая старт, не достигает апертуры, выход энергетически запрещён. Для окружности `rho=a` простое достаточное условие запрета выхода:

`J < -|kappa_m| a^m - a²/(2m²)`.

Условие консервативно: открытая энергетически разрешённая область ещё не означает, что конкретная траектория достигнет выхода. Само наличие интеграла не доказывает глобальное удержание.

### Важная оговорка для старта внутри круглой апертуры

Порог `J < -|κ_m|a^m-a²/(2m²)` корректен, но для чистого идеального мультиполя он **не выполняется ни для какого старта строго внутри** `ρ₀<a`. Минимум эффективного потенциала на радиусе `ρ` равен `V_min(ρ)=-|κ_m|ρ^m-ρ²/(2m²)` и строго убывает наружу. Для любого старта `J≥V_eff(ρ₀,α₀)≥V_min(ρ₀)>V_min(a)`. Более того, в конфигурационном множестве `V_eff≤J` из любого разрешённого старта можно двигаться по углу к ближайшей долине `κ_m cos(mα)=-|κ_m|`, где потенциал падает, а затем идти наружу по этой долине, где он продолжает падать. Значит, один интеграл Якоби не создаёт энергетически запрещённой компоненты, отделённой от апертуры. Это утверждение о доступности конфигураций; оно **не** утверждает, что динамическая траектория последует по такому пути или обязательно выйдет.

### Строгая, но грубая конечновременная нижняя граница

Для чистого поля порядка `m` модуль безразмерного ускорения внутри диска `ρ≤b≤a` ограничен `A_b=m|κ_m|b^(m−1)`. Пусть `T=2πN` и `d_b=b−A_bT²/2>0`. Тогда все начальные условия

`ρ₀<d_b`, `|u₀|<(d_b−ρ₀)/T`

остаются внутри радиуса `b` до `T`: при предположении первого достижения `b` интегральная оценка даёт `ρ(T)≤ρ₀+|u₀|T+A_bT²/2<b`, противоречие. Их безразмерный фазовый объём равен

`a₄,LB=π²d_b⁴/(6T²)`.

Для `m>2` максимум `d_b` по `b≤a` достигается при `b=min[a,(m(m−1)|κ_m|T²/2)^(−1/(m−2))]`. При `m=4` это `b=min[a,(6|κ_4|T²)^(−1/2)]`, а `d=2b/3` при внутреннем оптимуме; отсюда строгая оценка убывает как `N⁻⁶`. Оценка очень консервативна, требует, чтобы весь построенный малый диск координат и скорости лежал в заданном домене инжекции, и не приближает основной измеряемый объём удержания.

Для h50 одно гармонического контроля, извлечённого из V10 P4-поля, `κ₄=0.00516810547` при 250 V. При `N=1000` сертификат гарантирует только `ρ₀<6.03·10⁻⁴` (`r₀<4.82 μm`) и `|v₀|<4.82·10⁻⁴ m/s` из центра; `a₄,LB=5.49·10⁻²¹`, `A₄,LB=8.88·10⁻¹⁸ m⁴s⁻²`. Для h50 m=6 контроля `κ₆=0.00645354100`, `ρ₀<0.0181` (`r₀<145 μm`), `|v₀|<0.0145 m/s` и `A₄,LB=7.22·10⁻¹² m⁴s⁻²`. Оба подмножества лежат внутри V12-домена `r₀≤7.5 mm`, `E₀≤5 eV`, но оценки слишком малы для практического прогноза аксептанса. Таблица для `N=1000…100000` воспроизводится скриптом `scripts/finite_time_bound_v12.py` и сохранена как `validation/finite_time_bounds_v12.csv`.

## Что меняется при порядке m

При `m=2` полевая сила линейна, и линейная система допускает анализ Флоке. Стоячий квадруполь приводит к уравнениям Матье. При вращающемся квадруполе координаты обычно связаны, поэтому нужна матрица монодромии; автоматически называть систему скалярным уравнением Матье нельзя.

При `m=4` и `m=6` полевая сила нелинейна и в центре имеет нулевой линейный коэффициент. Ведущая псевдопотенциальная энергия пропорциональна соответственно `rho^6` и `rho^10`. Параметров Матье `a,q` недостаточно: нужны как минимум амплитуда безразмерной силы, начальные координаты и скорости, RF-фаза, апертура и горизонт наблюдения.

## Псевдопотенциал и адиабатичность

Для двух пиковых квадратур `E_c cos(Omega t)+E_s sin(Omega t)` усреднённая энергия в безразмерных единицах:

`Psi' = Lambda² (|grad F_c|²+|grad F_s|²)/4`.

В бегущем идеальном поле две квадратуры дают сумму `2 m² c_m² rho^(2m-2)`, поэтому `Psi'=kappa_m² m² rho^(2m-2)/2`. Для стоячего поля при одинаковой амплитуде одной квадратуры псевдопотенциал вдвое меньше. Это подтверждается сохранённой нормировкой V10: `U_stand=sqrt(2) U_rot` согласует ведущий собственный `m=4` член, но не высшие гармоники или перекрёстные члены.

Локальная оценка адиабатичности бегущей гармоники `epsilon_ad≈|kappa_m|m(m-1)rho^(m-2)` — оценка малого изменения поля на длине микродвижения, а не граница удержания. При m>2 она ухудшается с радиусом.

## Многогармоническое FEM-поле

При единой скорости вращения всех компонент с ненулевым угловым порядком сохраняется один интеграл вида `H-omega ell_z`, если осесимметричные компоненты стационарны. Временная осесимметричная компонента с ненулевой частотой не устраняется вращением координат. При несовпадающих скоростях рисунка или стоячих и вращающихся компонентах общей непрерывной вращательной симметрии обычно нет; применять один интеграл Якоби к полной FEM-суперпозиции нельзя.

Для полных A/B коэффициентов V7/V10 пространственные порядки `4,8,16,20,28,32,40,44` имеют две поляризационные спиральности. В идеальном 2D случае градиентные поля двух противоположных спиральностей ортогональны в скалярном произведении; поэтому ведущий `4×8` cross-term псевдопотенциала подавляется во вращающемся варианте, но остаётся в стоячем. Это известная проверяемая геометрическая закономерность, уже изученная для данной FEM-ловушки в V7/V10, а не новая универсальная теорема V12.

Для C измерены `m=6,18,30,42,…`; гармоническое m=6-поле является только контрольным пределом. До завершения четырёхмерных оценок `a4` и параметрических сканов никаких аналитических численных значений аксептанса не заявляется.
