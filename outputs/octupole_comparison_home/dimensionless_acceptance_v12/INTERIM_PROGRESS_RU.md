1. Довести широкую очередь до полного набора валидных состояний, проверить численные ошибки и зафиксировать оценки отдельно по FEM и аналитическим контролям.

После завершения N=1000 их можно продолжать с корректными вероятностями включения; отдельно добавить точечные траектории около границ, не смешивая их без весов в `S(N)`.

На этом этапе научно завершены теория и вычислительная инфраструктура; статистический результат о 4D-аксептансе ещё не получен.

## Дополнение: аналитическая конечновременная граница

Для чистого вращающегося m=4 интеграл Якоби не создаёт энергетически запрещённой внутренней области: у эффективного потенциала существует доступный канал к апертуре. Это не предсказывает фактический выход частицы. Независимо получена строгая конечновременная нижняя оценка по максимуму ускорения. На V12 m=4 контроле при 250 V и `N=1000` она гарантирует только `r₀<4.82 μm`, `|v₀|<4.82·10⁻⁴ m/s` из центра, с объёмом `A₄≥8.88·10⁻¹⁸ m⁴s⁻²`; величина слишком консервативна для практического аксептанса, но ограничение математически проверяемо. Формулы и таблица для m=4/6 и горизонтов 1000–100000 добавлены в `ANALYTICAL_RESULTS.md` и `validation/finite_time_bounds_v12.csv`.

## Дополнение: нормировка полей и парные контрасты

Аудит h50 показал, что при равных 250 V RMS-поле A/C меняет соотношение с радиусом: A/C≈3.02 при 4 mm, но C/A≈1.037 при 7.5 mm. Для отдельного matched-протокола правило теперь раздельно указано: B согласуется с ведущим m=4 A, реальный C по полному RMS-полю на `r_ref`, идеальный C — по ведущему m=6 на том же радиусе. При `r_ref=2/4/6 mm` нужны соответственно `3020.080/755.658/342.778 V` для FEM C и `3020.070/755.018/335.563 V` для идеального m=6 при A=250 V. Текущая массовая очередь остаётся равнопиковой; matched-протокол будет отдельным этапом.

Сводка производственных расчётов также содержит парные сравнения каждой FEM-модели с её одно гармонической абляцией, чтобы измерить суммарный эффект высших гармоник без повторных интеграций. Поправки к интервалам и matched-нормировке прошли четыре целевых методических теста.

Чтобы получить первый полный статистический результат до завершения всего скана, расписание очереди изменено только по порядку выполнения: все общие состояния A/B/C при 250 В идут первыми (4 × 256 × 3 = 3072 траектории), затем выполняются остальные модели и масштабы. На машине 12 логических CPU и около 7 ГБ доступной RAM; ранее измеренная загрузка поддерживает 8 workers, поэтому сохранено это значение.

Оставшийся порядок этапов:

1. Завершить базовый A/B/C 4D-ансамбль 250 В, фаза 0°, N=1000, затем сразу сохранить оценки `A4`, `a4`, долей удержания и парных интервалов отдельным этапом.

3. Возобновить широкий равнопиковый скан после базового результата; использовать его существующие checkpoints и сравнить FEM с одно гармоническими контролями по масштабу `Lambda`.
4. После равнопикового результата выполнить matched-нормировки на 4 мм и чувствительность 2/6 мм, затем фазу и условные направления скорости, не подменяя ими полный интеграл.
5. Продолжить заранее выбранные 64 состояния до 3000/10000 RF; к более длинным горизонтам переходить с теми же стартами и только после проверки накопленной динамики.

Для первого полного результата подготовлен `scripts/summarize_v12_baseline.py`. Он не интегрирует уравнения и не изменяет очередь: перед экспортом проверяет все 1024 общих Sobol-старта на каждой из A/B/C, полный горизонт, конфигурационный hash и отсутствие неразрешённых статусов; затем создаёт таблицу 3072 траекторий, репличные интервалы, парные сравнения и рисунок PDF/SVG/PNG. Подготовлен `scripts/analyze_v12_baseline_directions.py` для условного удержания по знаку `Lz0`, радиальной/тангенциальной скорости и заранее заданным энергетическим полосам 0–0.5–1–2–3–5 эВ. Он разделяет четыре Sobol-реплики, сохраняет неразрешённые случаи и строит отдельные CSV/JSON/PDF/SVG/PNG. Эти срезы будут условными вероятностями, не частями полного `A4`; знак `Lz0` и тангенциальный знак при `r0>0` — одна и та же геометрическая величина.

Утилита продолжения доработана для настоящей цепочки N=1000→3000→10000→…: каждый этап сохраняет ссылку на исходную таблицу стартов, а следующий этап читает состояние из предыдущих checkpoints и абсолютную фазу — без возврата к N=1000. Для папок продолжений, созданных старой версией без явной ссылки на таблицу стартов, предусмотрен проход по `source_run` к исходному run.
