# V12 — промежуточный отчёт, 2026-11-14

## Зафиксировано и опубликовано

- `master` включает результаты V11, первый V12-коммит теории и интегратора, исправления оценивания аксептанса и отдельную утилиту продолжения к большим временам. Все изменения отправлены обычными fast-forward push; принудительное переписывание истории не применялось.
- Полный локальный набор проверок: **130 passed**. Первоначальный запуск pytest из системного временного каталога дал ошибки доступа Windows; повторный запуск с временным каталогом внутри проекта завершился успешно.
- Добавлено продолжение от сохранённого состояния с абсолютной RF-фазой. Smoke-проверка продолжила новую траекторию с `N=1` к `N=2`, а повторный запуск той же очереди вернул checkpoint без повторной интеграции.
- Независимый пилот на полях h35/h50 охватил 8 одинаковых новых физических состояний для A/B/C: классификации совпали в 24 из 24 пар. Это малый аудит сетки, не полноценная карта.

## Текущий массовый расчёт

- Run: `e6bf3a33795e4a5354a8_equal_broad_lambda_h50_4x256`.
- План: 43 008 траекторий, 8 процессов; 1 024 общих состояния Sobol, четыре независимых скремблирования, 42 сочетания модели и масштаба напряжения.
- Поля: реальные FEM A/B/C на h50 и ведущие одно гармонические контроли A/B/C, взятые из коэффициентов FEM.
- Домен: равномерная по площади область координат `r₀≤7.5 mm`; равномерный по площади диск скоростей `E₀≤5 eV`; RF-фаза 0°; горизонт 1000 периодов.
- Протокол: одинаковые пиковые напряжения, семь масштабов `0.25, 0.5, 0.75, 1, 1.5, 2, 4` от 250 V. Интегратор DOP853, h50 N48, `rtol=2·10⁻¹⁰`, максимальный шаг `T_RF/64`.
- На момент отчёта завершено **80/43 008** траекторий: 52 выхода и 28 удержаний. Очередь ещё не завершила ни одной полной реплики по всем моделям и масштабам, поэтому оценки объёма и сравнительные выводы пока не публикуются.
- По ранней скорости около 0.22 задачи/с грубая оценка составляет ~54 часа при сохранении темпа; это не гарантирует срок, так как стоимость сильно зависит от того, когда траектории выходят. Каждый worker записывает состояние каждые 250 периодов; прерванные интервалы можно продолжить.

## Следующие шаги

1. Довести широкую очередь до полного набора валидных состояний, проверить численные ошибки и зафиксировать оценки отдельно по FEM и аналитическим контролям.
2. На выбранных масштабах повторить ансамбль на h35 и проверить расхождения классификаций с h50.
3. Провести расширение области инжекции и сравнение при согласовании эффективного поля на нескольких опорных радиусах.
4. Outcome-blind выборка для оценки общего `S(N)` уже зафиксирована: 16 стартов на каждую Sobol-реплику, 64 точки всего, те же состояния для A/B/C при масштабах 0.5/1/2. После завершения N=1000 их можно продолжать с корректными вероятностями включения; отдельно добавить точечные траектории около границ, не смешивая их без весов в `S(N)`.

На этом этапе научно завершены теория и вычислительная инфраструктура; статистический результат о 4D-аксептансе ещё не получен.

## Дополнение: аналитическая конечновременная граница

Для чистого вращающегося m=4 интеграл Якоби не создаёт энергетически запрещённой внутренней области: у эффективного потенциала существует доступный канал к апертуре. Это не предсказывает фактический выход частицы. Независимо получена строгая конечновременная нижняя оценка по максимуму ускорения. На V12 m=4 контроле при 250 V и `N=1000` она гарантирует только `r₀<4.82 μm`, `|v₀|<4.82·10⁻⁴ m/s` из центра, с объёмом `A₄≥8.88·10⁻¹⁸ m⁴s⁻²`; величина слишком консервативна для практического аксептанса, но ограничение математически проверяемо. Формулы и таблица для m=4/6 и горизонтов 1000–100000 добавлены в `ANALYTICAL_RESULTS.md` и `validation/finite_time_bounds_v12.csv`.

## Дополнение: нормировка полей и парные контрасты

Аудит h50 показал, что при равных 250 V RMS-поле A/C меняет соотношение с радиусом: A/C≈3.02 при 4 mm, но C/A≈1.037 при 7.5 mm. Для отдельного matched-протокола правило теперь раздельно указано: B согласуется с ведущим m=4 A, реальный C по полному RMS-полю на `r_ref`, идеальный C — по ведущему m=6 на том же радиусе. При `r_ref=2/4/6 mm` нужны соответственно `3020.080/755.658/342.778 V` для FEM C и `3020.070/755.018/335.563 V` для идеального m=6 при A=250 V. Текущая массовая очередь остаётся равнопиковой; matched-протокол будет отдельным этапом.

Сводка производственных расчётов также содержит парные сравнения каждой FEM-модели с её одно гармонической абляцией, чтобы измерить суммарный эффект высших гармоник без повторных интеграций. Поправки к интервалам и matched-нормировке прошли четыре целевых методических теста.
