## Первая законченная оценка четырёхмерного аксептанса

Оценён конечновременный объём удержания при равных пиковых напряжениях 250 В на электродах, фазе 0°, h50/N48 FEM, горизонте 1000 RF-периодов, массе 100 000 Th и заряде +e. Общий домен: равномерные по площади старты в диске `r₀≤7.5 мм` и равномерные по площади скорости в диске `E₀≤5 эВ`. Использованы 4 независимые скремблированные Sobol-реплики по 256 одинаковых A/B/C состояний; все 3072 исхода завершены. Безразмерная связь `a₄=A₄/(R⁴Ω²)` использует `R=8 мм`, `Ω=2π·100 кГц`, `Λ=0.00954688286937`. Полный объём домена равен `0.00331256099476` в безразмерных единицах или `5.3565303313 м⁴·с⁻²`.

| A — вращающийся октуполь | 888/1024 | 0.8672 [0.8347, 0.8997] | 0.00287261 [0.00276496, 0.00298026] | 4.64512 [4.47105, 4.81918] |

Парные оценки используют общие начальные состояния. Для A−B разность долей удержания равна `0.7383 [0.7050, 0.7716]`, а отношение средних A/B — `6.727 [6.176, 7.595]`. Для A−C разность `−0.0088 [−0.0452, 0.0276]`, отношение A/C `0.990 [0.965, 1.004]`: при этой конечной фазе/амплитуде нет убедительного различия между A и C. Для B−C разность `−0.7471 [−0.7502, −0.7440]`, отношение B/C `0.147 [0.132, 0.156]`. Интервалы по отдельным оценкам построены по четырём Sobol-репликам (Student-t, df=3); интервалы отношений — парным bootstrap реплик. Эти выводы относятся только к выбранному домену и N=1000, не к бесконечному удержанию.

Срезы по исходной энергии показывают снижение условного удержания от низкой полосы `E₀∈[0,0.5) эВ` к высокой `E₀∈[3,5] эВ`: парные разности «высокая минус низкая» равны A `−0.1439` (95% CI `[−0.1950,−0.0927]`), B `−0.3381` (`[−0.3912,−0.2851]`), C `−0.0958` (`[−0.1535,−0.0381]`). Это условные доли внутри энергетических полос, не части полного интеграла A₄. Для парных контрастов знака `Lz₀` и радиальной скорости все четыре-репличные 95% интервалы включают ноль: например, контраст positive-minus-negative по `Lz₀` равен A `−0.0188` (`[−0.0797,0.0421]`), B `+0.0503` (`[−0.0370,0.1376]`), C `−0.0131` (`[−0.0529,0.0268]`). Поэтому эта базовая выборка не разрешает самостоятельную асимметрию по знаку начального углового момента или радиального направления; для вращательной зависимости нужны специально спаренные направления и фазы. Все данные и парные интервалы сохранены в `results/baseline_equal_250V_phase0_N1000/direction_analysis_v12/`.

## Следующий вычислительный этап

Широкий обзорный ансамбль использует общий рандомизированный Sobol-набор для трёх FEM-моделей A/B/C и трёх одно гармонических контрольных моделей, одинаковый домен `r0≤7.5 mm`, `E0≤5 eV`, фазу 0°, горизонт 1000 RF-периодов и равные пиковые 250 V. Для h50 запущена очередь с масштабами `[0.25, 0.5, 0.75, 1, 1.5, 2, 4]`, четырьмя независимыми скремблированиями по `2^8` состояний каждое: 43 008 интеграций. По пилотной цене ориентир около 73 wall-hours по средней цене траекторий и до ~111 часов по медианной; это не гарантия. Контрольные поля берут ведущие коэффициенты из h50 FEM. Состояние каждой траектории сохраняется каждые 250 периодов, завершённые задания не повторяются. После обзора будут выбраны до трёх исследовательских якорей; для подтверждения предпочтительны новые независимые скремблирования общим размером `2^12`, а не повторное использование точек, по которым эти якоря выбирались.

После равнопиковых оценок будут выполнены протокол согласованного эффективного поля с явным радиусом сравнения, фазовые срезы, фиксированные энергетические оболочки и продолжение заранее отобранной репрезентативной выборки к `N=3000…100000`. Любая точка, меняющая статус между h35/h50 или строгими интеграторами, останется численно неразрешённой.

### Фактические параметры широкой равнопиковой очереди

Из замороженных `config.json` и `model_coefficients.json` получены реальные значения

\[
\Lambda=\frac{qU}{M\Omega^2R^2},\qquad
\kappa_m=\Lambda c_m
\]

для каждого напряжения. Здесь `c_m` берётся из ведущего FEM-коэффициента в согласованной с аналитическим одно-модовым контролем квадратурной конвенции; для A имеются две равные вращающиеся квадратуры, для B/C — одна стоячая. Полные FEM-модели по-прежнему содержат высшие пространственные гармоники. Таблица ниже — настройки интегрирования, а не результаты аксептанса.
