# V12 — численные методы оценки аксептанса

## 1. Расчётный объект и заранее фиксированный домен

Для каждого эксперимента до запуска фиксируются:

1. физический четырёхмерный домен `D` или безразмерный домен `D′`;
2. распределение/мера, относительно которой проводится интегрирование;
3. модель поля, конфигурация амплитуд и нормировка;
4. список RF-фаз и горизонты `N`;
5. критерий выхода, FEM-область применимости и численные параметры;
6. целевой уровень неопределённости либо условие остановки набора.

Все модели сравниваются на одной парной выборке физических состояний. Нельзя выбирать новые состояния для интеграла только среди уже удержанных и затем считать их равновесными исходной выборке. Дополнительные адаптивные состояния допустимы, если их веса/объёмы учтены отдельно.

В качестве простого воспроизводимого тестового домена можно взять произведение диска координат `x₀²+y₀²≤R_inj²` и диска скоростей `vₓ₀²+vᵧ₀²≤v_max²`, причём `R_inj<R_ap` и весь координатный домен лежит внутри корректной области FEM. Тогда

\[
V_D=\mathrm{Vol}(D)=π²R_{inj}²v_{max}²,
\quad
V_{D′}=π²ρ_{inj}²u_{max}².
\]

Это пример параметризации, а не универсально правильное распределение для экспериментального источника. Физический домен должен быть обоснован условиями инжекции. Если применяются прямоугольный диапазон компонент скорости, кольцевой диапазон энергий или коррелированный пучок, задаются именно они и вычисляется их точный объём либо плотность.

## 2. Равномерное интегрирование и рандомизированная Sobol-выборка

Для равномерной выборки `{z_i}` внутри `D` простая оценка объёма:

\[
\widehat A_4=V_D\,\widehat p_N,
\qquad
\widehat p_N=\frac1n\sum_{i=1}^n I_N(z_i).
\]

Аналогично `â₄=V_D′·(1/n)ΣI_N`. Для дискового домена точки можно генерировать преобразованием `s,θ∈[0,1]×[0,2π)`: `r=R_inj sqrt(s)`, `θ=2πt`; то же преобразование используется для вектора скорости. Корень из равномерной переменной необходим для равномерности по площади.

Для четырёхмерного интеграла предпочтительна рандомизированная Sobol-сетка с независимыми цифровыми скремблированиями. Используют вложенные объёмы `n=2¹⁰, 2¹², 2¹⁴, …`; последовательность каждого скремблирования детерминирована своим сохранённым seed. На каждом уровне те же точки применяются ко всем моделям, фазам и требуемым горизонтам, когда это возможно. Это уменьшает дисперсию разности и делает сравнения парными.

При фиксированной энергии `E` используют отдельное трёхмерное сечение `(x,y,β)`. Для равномерной меры `d²r dβ` точки координат равномерны по заданной области, а `β` — равномерен на `[0,2π)`. Для объёма в диапазоне энергий учитывают якобиан

\[
d²v=\frac1M dE\,dβ.
\]

Поэтому равномерная выборка в `(E,β)` с постоянным весом оценивает соответствующий фазовый объём по скорости. Если целевое распределение по энергии неравномерно, его плотность вводится явно.

## 3. Неравномерные выборки и адаптивная граница

Для выборки с известной плотностью `p(z)` по отношению к объёму фазового пространства используют оценку важностного интеграла

\[
\widehat A_4=\frac1n\sum_{i=1}^n\frac{I_N(z_i)}{p(z_i)}.
\]

Её неопределённость рассчитывают из тех же взвешенных вкладов и сообщают эффективный размер выборки. Выборка из условного распределения `z | I_N=1` не оценивает `A₄` без вероятности попадания и соответствующего поправочного веса.

Для локального уточнения границ фазовое пространство делится на непересекающиеся страты `D_j` известного объёма. В каждой страте оценивается доля удержания `p̂_j`, после чего

\[
\widehat A_4=\sum_j V_j\widehat p_j.
\]

Число точек в стратах можно распределять по пилотной оценке, в том числе концентрируя вычисления у границы, поскольку итоговый вклад каждой страты умножается на её исходный объём. Альтернатива — отдельный независимый контрольный набор для оценки всей области с весами известного дизайна. Плотность выборки, правило адаптации, объёмы страт и seeds журналируются.

Дискретные карты не сглаживаются и не заполняются интерполяцией. Бинарные исходы существуют только для рассчитанных стартов; неизвестные, численно недостоверные и нерассчитанные состояния визуально отделяются. Адаптивная сетка уточняет сами начальные условия, а не подменяет их предсказанными классами.

## 4. Оценка неопределённости и парные сравнения

### Обычная независимая Monte Carlo выборка

Для независимой равномерной выборки доли `p̂` стандартная ошибка оценивается `sqrt[p̂(1-p̂)/n]`. При малом числе выходов/удержаний вместо симметричного нормального интервала используют Wilson или точный биномиальный интервал; около 0 и 1 обычная оценка ошибки особенно ненадёжна. Интервал объёма получается умножением границ интервала доли на `V_D`.

### Рандомизированная Sobol-оценка

Для `K` независимых скремблирований считают оценку отдельно для каждого полного скремблирования, `Â_k`. Среднее `K` оценок — итоговая оценка; эмпирическая стандартная ошибка равна `s(Â_k)/sqrt(K)`. Отчёт указывает `K`, `n` на скремблирование, seeds и чувствительность результата к удвоению `n`. Разброс скремблирований — оценка численной неопределённости рандомизации, а не безусловная математическая гарантия покрытия для любой сложной границы. Для итоговых результатов число независимых скремблирований увеличивается, если межскремблированная ошибка нестабильна.

### Сравнение моделей на общих состояниях

Для оценки доли удержания, `a₄`, `A₄` и парной разности дополнительно выводится двусторонний 95% интервал Стьюдента по независимым скремблированиям (`K−1` степеней свободы). Отношение средних долей имеет отдельный парный bootstrap-интервал по репликам. При малом числе реплик эти интервалы могут быть широкими и дискретными; это приближённая оценка межскремблированной неопределённости, не гарантия покрытия для любой сложной границы.

Для пары моделей `A,B` на одинаковых точках оценивают

\[
\widehat{ΔA_4}=\frac{V_D}{n}\sum_i\left[I_{N,A}(z_i)-I_{N,B}(z_i)\right].
\]

Для каждой реальной FEM-модели дополнительно сравнивается одно гармоническая абляция того же пространственного порядка (`A`–`idealA`, `B`–`idealB`, `C`–`idealC`). Это парное сравнение на тех же стартах оценивает суммарное влияние удалённых гармоник и изменения их интерференции; оно не приписывает эффект отдельному коэффициенту `m=8` без специальной контролируемой абляции.

Неопределённость вычисляется по парным разностям, а не как будто два независимых ансамбля. Для Sobol-выборки разности сначала усредняются внутри каждого общего скремблирования, а затем оценивается разброс по скремблированиям. Обязательно приводятся оба абсолютных значения, абсолютная разность и доверительный/рандомизационный интервал. Отношение `A₄,A/A₄,B` приводят только если знаменатель устойчиво ненулевой; точечную оценку вычисляют как отношение средних долей удержания, а неопределённость — парным bootstrap по независимым рандомизированным репликам. Усреднять отношения отдельных реплик нельзя, поскольку это даёт иной, потенциально смещённый показатель.

Численная ошибка интегратора, незавершённый запуск или отсутствующий результат остаются `unresolved` и не кодируются как выход. Оценка модели допускается только если каждый запланированный старт в каждой независимой реплике получил валидный исход `retained` или `escaped`. Парное сравнение требует полного совпадения набора валидных состояний в обеих моделях; в противном случае оно откладывается до завершения/повтора проблемных запусков, а не рассчитывается по неполному знаменателю.

Для вероятностной передачи `P_N` при экспериментальном распределении используют парное сравнение индикаторов с теми же физическими частицами, сэмплированными из этого распределения. Геометрический `A₄` и распределительно-взвешенный `P_N` маркируются отдельно.

## 5. Сходимость по числу точек и критерий остановки

На каждом уровне `2¹⁰, 2¹², 2¹⁴, …` сохраняют оценку, разброс независимых скремблирований, число парных несовпадений, долю unresolved и стоимость. График сходимости строится по вычисленным точкам. Сетку увеличивают, пока заранее заданная точность для абсолютного `A₄` и основных разностей конфигураций не достигнута, либо пока отчётливо не показана остаточная неопределённость и причина остановки.

Для узких удерживаемых островов глобальная средняя ошибка может скрыть локальную редкость. Поэтому дополнительно проверяют чувствительность к стартовым случайным скремблированиям и проводят стратифицированное уточнение в областях неоднородности. Но локальная детализация не заменяет оценку вклада этой области в полный объём с корректным `V_j`.

## 6. Фазы, направления и горизонты

- Если требуется фиксированная RF-фаза, она идентична для парных расчётов всех моделей.
- Для фазового среднего интегрируют по `[0,2π)` с явной квадратурой/рандомизированной выборкой и проверяют предполагаемые симметрии преобразованием начальных условий. Несколько произвольных фаз не объявляются фазовым средним.
- Направление скорости сохраняется как `β=atan2(vᵧ,vₓ)`; сечения по `L_z=M(xvᵧ−yvₓ)`, радиальным и тангенциальным направлениям рассчитываются на общей выборке и не смешиваются с интегралом без их меры.
- Для набора горизонтов используют одни и те же начальные условия. Событие выхода поглощающее, поэтому точная динамическая классификация монотонна: `I_{N₂}≤I_{N₁}` при `N₂>N₁`. Численные ошибки могут нарушить наблюдаемую монотонность, и такое несоответствие требует расследования.

При продолжении траектории с `N₁` до `N₂` сохраняют состояние `(x,y,vₓ,vᵧ,t)` и абсолютную RF-фазу. Вышедшие состояния навсегда остаются `escaped`; удержанные продолжаются только на интервале `(N₁,N₂]`. Checkpoint содержит параметры интегратора или полностью специфицированное безопасное перезапускание сегмента, чтобы не повторять уже засчитанные периоды. Сходимость проверяется на границах сегментов, а численный перезапуск не должен сбрасывать RF-фазу.

Оценка выживания

\[
S(N)=\frac1n\sum_{i=1}^{n}I_N(z_i)
\]

имеет смысл только относительно той же заранее зафиксированной выборки и того же распределения начальных условий. Доля среди отобранных заранее удержанных частиц — условная характеристика подвыборки, а не `S(N)` исходного ансамбля. Конечное удержание до `100000` периодов не доказывает бесконечную устойчивость.

Для статусов `uncertain/incomplete` приводятся границы оценки: нижняя — только гарантированно удержанные, верхняя — гарантированно удержанные плюс все неразрешённые точки. Неопределённость траекторной классификации нельзя маскировать статистическим интервалом выборки.

## 7. Численная сходимость траекторий

Четырёхмерный интеграл оценивает объём только настолько надёжно, насколько надёжны индивидуальные `I_N`. Поэтому пилотный subset должен измерить стоимость и проверить:

1. массовое поле на N48 h35/h50 и его область интерполяции;
2. прямое P4 FEM для репрезентативных ранних, поздних и граничных событий;
3. строгий DOP853 с уменьшением максимального шага и tighter tolerances;
4. точность локализации первого события выхода;
5. совпадение классификации и времени выхода между уровнями проверки.

Точки, чья классификация меняется между h35 и h50 либо между стандартным и строгим интегратором, маркируются пространственно/численно неразрешёнными и не входят в утверждения о тонкой границе. Их вклад в общий acceptance сообщается через указанные ниже/верхние границы или повторно уточняется. Параметры сходимости нельзя подбирать после просмотра желаемого результата.

## 8. Checkpoint, журнал и параллельные расчёты

Каждое задание идентифицируется хешем конфигурации, моделью, индексом точки/скремблирования, фазой и горизонтом. Конфигурация включает физические параметры, версию поля/FEM-сетки, нормировку, начальное состояние, seed и настройки решателя. Каждый worker пишет отдельные checkpoint-файлы/шард; агрегатор объединяет только завершённые валидные записи. Запись checkpoint выполняется атомарно либо через временный файл с последующей заменой; общая запись несколькими worker в один JSON/CSV без блокировки запрещена.

Число процессов выбирается по пилотному времени на траекторию и доступным RAM/ядрам. Перед массовым запуском измеряют фактическую производительность и максимальную память, ограничивают число потоков BLAS/OpenMP, не запускают тяжёлый FEM-решатель одновременно с массовым сканом при нехватке памяти. Каждая запись должна позволять точно выяснить, что вычислено, что было возобновлено и что пропущено; завершённые задания не запускаются снова.

## 9. Минимальные таблицы результата

Для каждой оценки сохраняются: `D`/`D′` и его объём; преобразование выборки и вероятность/вес каждой точки; число точек/реплик; `N`, `φ₀`, настройки модели; `A₄`/`a₄` либо `P_N`; оценка ошибки и интервалы; неопределённые статусы; число парных discordant-классификаций; wall time, CPU workers и checkpoint coverage. Для каждого состояния сохраняются сами начальные условия в физических и безразмерных единицах, статус, время первого выхода, максимум радиуса, версия поля и валидационные флаги.
