# V13: точная линейная устойчивость центра

Разложение силы при (x,y\to0) даёт

\[
x''+2(\alpha+\beta\cos\tau)x=0,\qquad
y''-2(\alpha+\beta\cos\tau)y=0.
\]

Октуполь исчезает из якобиана силы: его вклад имеет порядок (O(\rho^3)). Поэтому **линейная диаграмма одинаковая для Q, Q+RO и Q+SO при одинаковых (\alpha,\beta)**. Любая различная передача масс возможна только из-за конечной апертуры, нелинейной силы, начальных условий и времени пролёта.

После (z=\tau/2) в соглашении (w_{zz}+(a-2q_M\cos2z)w=0): (a_x=8\alpha, q_{M,x}=-4\beta), (a_y=-8\alpha, q_{M,y}=4\beta). Физический заряд (Q) в (q_M) не подразумевается.

Численный метод: фундаментальную матрицу каждой координаты интегрировали за период (2\pi), DOP853, относительный допуск (2\cdot10^{-11}), абсолютный (2\cdot10^{-13}). Симплектический детерминант должен быть 1. Строгая устойчивость требует (|\mathrm{tr}M_x|<2) **и** (|\mathrm{tr}M_y|<2), с запасом (10^{-8}). При (|\mathrm{tr}M|\approx2) статус остаётся «граница/неразрешено»; без проверки собственных векторов нельзя считать её устойчивой. В частности, при (\alpha=\beta=0), (M=\left(\begin{smallmatrix}1&2\pi\\0&1\end{smallmatrix}\right)): жорданов блок вызывает линейный дрейф, несмотря на (|\mathrm{tr}M|=2).

Пилотная сетка ([-0.12,0.12]\times[0,0.35]), 49×71: 207 строго устойчивых, 3271 неустойчивых, одна точка границы. Максимальная ошибка (|\det M-1|=8.85\cdot10^{-11}). Данные в `floquet_grid.csv`, конфигурация в `floquet_config.json`, рисунок `floquet_stability.{svg,pdf,png}`. Это дискретная карта со строгой классификацией **только в вычисленных точках**; цвет между ними нужен для отображения, не является новым вычислением.

Независимый контроль стандартной теорией Матье: при (\alpha=0) первая граница задаётся (b_1(4\beta)=0), откуда (\beta=0.2270115834336444). Сетка шагом 0.005 имеет последнюю строго устойчивую точку 0.225. На общей линейной диаграмме параметр (\kappa) отсутствует. При изменении (M/Q) и фиксированных напряжениях рабочая точка движется по лучу (\alpha,\beta,\kappa\propto Q/M), поэтому даже обычный квадруполь даёт масс-селективную границу.

Эта карта не предсказывает долю передачи конечного пучка. Вблизи границ потребуется адаптивное уточнение по (\alpha,\beta) и проверка сходимости классификации при более строгих допусках.
