# V13.2 — численная проверка этапа A

## Модель и масштабирование

Идеальная модель взята из `three_phase_trap.mass_filter_v13`: при `κ=0` остаётся RF/DC квадруполь; RO использует `Re[z⁴ exp(−iτ)]`, SO — `Re[z⁴] cosτ`. Знак `η=−0.05` задаёт октупольную RF-фазу `π` относительно положительной опорной фазы квадруполя. Для массового скана `α,β,κ∝1/μ`, при `Q=+e`, `f=100 kHz`, `R=8 mm`, `M₀=3200.0465226 Th`.

Реальные leading-harmonic коэффициенты V13.1 `c₄=0.5413395699439`, `c₂=d₂=0.7718255558274` использовались только при сопоставлении идеальных коэффициентов с электродными напряжениями и FEM полем; идеальные интеграции имеют нормировку гармоник `c₄=c₂=d₂=1`. Таблица всех 12 фактических пиков для сравниваемого питания лежит в `stage_a_electrode_voltage_peaks.csv`: максимумы составляют `219.3143 V` для Q и `232.8591 V` для Q+SO/Q+RO, все ниже 250 V.

## Интеграции и возобновление

- Идеальный интегратор: SciPy DOP853, `rtol=2e−10`, `atol=2e−12`, `max_step=2π/64`, событие первого пересечения `ρ=1`, максимум радиуса оценивается также в серединах dense-output шагов.
- Общие состояния одного индекса, обе RF-фазы и параметры моделей сохранены в trajectory CSV. Для выхода записывается первое время и `max ρ`; численная ошибка/неразрешённый статус не заменяется потерей.
- 100→300 и 300→1000 продолжение реплики `N=128` выполнялось с сохранённого состояния и несброшенным абсолютным τ; checkpoints содержат каждый завершённый запуск.
- 576 совпадающих точек `μ=1.00,1.05,1.10` на 100 периодах взяты из точного V13.1 идеального расчёта. Перекрёстная проверка совпала по статусам `576/576`, по записанным `max ρ` — точно.
- В идеальном Stage A pilot/fine/replica/strata исходов `numerical_error`/unresolved нет.

## Линейный Floquet контроль

Для каждого значения `μ` вычислены монодромии обеих осей. Строгая устойчивость означает одновременно `|tr M_x|<2` и `|tr M_y|<2`; равенство границе не помечается как устойчивость. Вдоль массового луча найденные границы: `μ=0.9734782388` (ось x, `tr M_x≈−2`) и `μ=1.0872192808` (ось y, `tr M_y≈+2`). Центр строго устойчив при `μ=1.04`; октуполь отсутствует в линейном якобиане и не изменяет эту диаграмму.

Таблицы: `stage_a_floquet_mass_scan.csv`, `stage_a_floquet_mass_boundaries.csv`. Точки у границы оставлены как `boundary_or_unresolved` согласно запасу по `2−|tr M|`.

## Полное h50 P4 FEM

Новая V13.2 точка `μ=1.04` рассчитана в полном поперечном h50 P4 FEM поле, без усечения высших пространственных гармоник. Использованы существующие V13.1 m=4 и m=2 unit-voltage решения и mesh; новая FEM геометрия/сеточная генерация не выполнялась. Входная выборка seed 131 и фазовое соглашение сохранены. Совмещённый P4 градиент построен линейной комбинацией двух ранее проверенных базисов на общей геометрии.

В основной проверке `N=32`, `rtol=3e−9`, `atol=3e−11`, шаг `2π/64`, статусы прослежены до 300 RF периодов. Неразрешённых исходов нет. Для пограничной выборки из 22 trajectory cases выполнено независимое повторение с шагом `2π/128`; статусы 100/300 периодов совпали во всех случаях. Максимальное изменение времени выхода составило 3.9178 периода. Все отдельные пары и `delta_exit_periods` перечислены в `stage_a_full_fem_h50_p4/step_refinement/trajectory_comparison.csv`.

В V13.1 имеется сравнение коэффициента c₂ на h70 сетке, но второго полного P4 поля для этой новой массовой точки нет. Поэтому h50→h70 сходимость траекторий V13.2 здесь не заявляется. Расхождение идеальной модели и FEM при μ=1.04 (идеальное N=128: RO 84/128, SO 98/128 за 100; FEM N=32: RO 21/32, SO 21/32) рассматривается как материальный эффект высших геометрических гармоник и/или входной ансамблевой вариации, а не сглаживается подгонкой.
