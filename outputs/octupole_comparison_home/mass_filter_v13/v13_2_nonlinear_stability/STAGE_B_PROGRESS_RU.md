# V13.2 — состояние этапа B

Дата остановки: 2026-11-15. Вычисление приостановлено по просьбе пользователя для продолжения на следующий день.

## Что подготовлено

Запущена грубая карта конечновременного удержания на сетке `15×19` по `(α, β)`, при `η=−0.05,+0.05` и соответствующем чистом квадруполе `η=0`. Для каждой точки заданы две начальные RF-фазы (`0°`, `90°`) и общий ансамбль из восьми состояний. Используются идеальная полная нелинейная модель, апертура `ρ=1`, горизонт `100` RF-периодов и интегратор `DOP853` с протоколом из `stage_b_parameters.json`. Всего запланировано `22 800` интеграций.

На момент приостановки записано `7 647` уникальных завершённых задач из `22 800`; `15 153` остаются. Проверка `validate_v13_2_stage_b_checkpoint.py` подтвердила отсутствие повторных ключей и неразрешённых статусов в завершённой части. В checkpoint содержатся `3 944` выхода и `3 703` удержания; из-за порядка постановки задач эта частичная доля **не является оценкой удержания карты** и здесь физически не интерпретируется.

## Возобновление

Checkpoint `stage_b_checkpoint.jsonl` записывался после каждой завершённой траектории и сохранён для продолжения. Драйвер пропускает уже завершённые ключи задач и продолжает оставшиеся:

```powershell
.\.venv\Scripts\python.exe scripts\run_v13_2_stage_b_nonlinear_map.py --workers 8
```

Перед возобновлением можно проверить целостность:

```powershell
.\.venv\Scripts\python.exe scripts\validate_v13_2_stage_b_checkpoint.py
```

После завершения драйвер создаст итоговые trajectory/summary CSV, строгую Floquet-сетку и границы, проверку допустимости напряжений, отдельные карты Q/SO/RO и времени выхода. До окончания всех задач окончательные карты не создавались, поэтому здесь нет интерполяции отсутствующих точек.

## Ограничения на текущем срезе

- По этой частичной записи нельзя оценить форму нелинейной области, парные эффекты RO−Q или RO−SO, фазовую зависимость карты либо физически перспективные режимы.
- Этапы C (частоты и резонансная структура), D (сечения Пуанкаре и показатели Ляпунова) не запускались. Для них пока нет отобранной и проверенной рабочей области.
- Предварительная классификация не распространяется на полное FEM-поле, асимптотическую устойчивость или передачу через фильтр конечной длины.
