# V13: FEM базисы и проекции гармоник

## Граничная задача и ориентация

Использованы **сохранённые** Gmsh секторные сетки `outputs/meshes/gmsh_{70,50}um/sector.msh`; геометрия не генерировалась заново. Квадрупольная задача решает `∇²H₂=0` с единичным комплексным потенциалом на электроде 0 и нулём на внешнем корпусе. Условие на секторном шве выведено из нового электродного базиса: `H₂(R₃₀ x)=exp(iπ/3)H₂(x)`. Поэтому вещественная часть на электроде `j` равна `cos(2θ_j)`, мнимая — `sin(2θ_j)`. Центральный DOF фиксирован нулём. Это **не** октупольный множитель `exp(−2πi/3)` из сохранённого RF-решения.

Решатель `run_quadrupole_fem.py` выполняет P2/P4 Galerkin FEM с комплексным квазипериодическим отождествлением степеней свободы. Для m=2 задача на секторе эквивалентна полной задаче по единственности решения Дирихле и симметрии геометрии. Аналогичное доказательство не даёт права переносить на неё прежний октупольный множитель. На внешнем корпусе — 0 В. Напряжения внутри металлических электродов не интерполируются как область вакуума.

## Нормировка и результаты

Для единичного пространственного базиса `G₂=Re H₂` использована проекция `c₂(r)=[π(r/R)²]⁻¹∫G₂(r,θ) cos2θ dθ`, `R=8 мм`. Синусная проекция должна быть нулевой при выбранной оси. Численная квадратура: 2048 равномерных углов на каждой окружности, со сдвигом на 0.123 шага для обхода точного шва. Для октуполя коэффициент `c₄` взят из независимого сохранённого P4 аудита V10/V12: коэффициент комплексной `H₄` при `r⁴ exp(−4iθ)`, умноженный на `R⁴`. В конвенции V12 `c₄=0.5413395699434914` для h50, с округлением/способом извлечения, эквивалентным найденному здесь `0.5413395699439091`. Это коэффициент при **единичном напряжении выбранного октупольного базиса**, `R=8 мм` и указанной фазе, а не универсальная константа геометрии.

| Базис | Сетка и порядок | Коэффициент при R=8 мм | Проверка |
|---|---:|---:|---|
| октуполь `G₄c,G₄s` | h50 P4 | `c₄≈0.541339569944` | сохранённый FEM V10/V12 |
| октуполь `G₄c,G₄s` | h35 P4 | `c₄≈0.541359663231` | относительное отличие 3.71×10⁻⁵ |
| квадруполь `G₂` | h70 P2 | `c₂=d₂≈0.77179706` | контроль порядка элемента |
| квадруполь `G₂` | h70 P4 | `c₂=d₂≈0.771796696934` | остаток 6.13×10⁻¹⁶ |
| квадруполь `G₂` | h50 P4 | `c₂=d₂≈0.77182555583` | остаток 4.54×10⁻¹⁶; отличие h70 P4 3.74×10⁻⁵ |

По h50 P4 `c₂(r)` меняется менее чем на 3×10⁻¹² между `r=0.5` и `8 мм`, а паразитная нормированная синусная компонента `m=2` не превышает `7×10⁻¹¹`. Это согласуется с регулярной гармоникой `r²` и выбранной ориентацией. Равенство `c₂=d₂` здесь точное в рамках **одной квазистатической пространственной задачи**: RF и DC используют одинаковую функцию `G₂`, различается только временной коэффициент. Реальные частотные импедансы источника этим расчётом не охвачены.

При `r=R` у квадруполя заметная гармоника `m=10`: косинусный коэффициент `≈0.06709184`, то есть около 8.7% ведущей квадрупольной амплитуды потенциала. У сохранённого октуполя гармоника `m=8` при h50 P4 даёт `≈0.178349` против `c₄≈0.541340`. Поэтому близко к апертуре динамику нельзя надёжно представлять только ведущими `m=2,4`; полное FEM-поле нужно в контрольных траекториях. В центральной области относительные примеси убывают как соответствующие дополнительные степени `r/R` (для квадруполя `m=10`: `(r/R)^8`).

Исходные таблицы `quadrupole_h*_P*_harmonics.csv` содержат амплитуды `m=0,2,4,6,10` для семи радиусов; одноимённые JSON — хеш сетки, размер системы, остаток, порядок элемента и конвенции. P4 октупольный источник: `../physical_verification_v10/data/p4_harmonics/native_p4_harmonic_coefficients.csv` и аудит JSON. `G₄c=Re H₄`, `G₄s=−Im H₄`; так `U₄[G₄c cosτ+G₄s sinτ]` имеет ведущий член `U₄c₄(r/R)^4 cos(4θ−τ)`.

Оставшаяся проверка перед количественной FEM передачей: собрать полное пространственное поле двух базисов, сверить его с прямым решением для нескольких мгновенных комбинаций и сравнить градиенты/траектории. Приведённые коэффициенты — проверенный результат этапа II, но не замена этой динамической проверки.
