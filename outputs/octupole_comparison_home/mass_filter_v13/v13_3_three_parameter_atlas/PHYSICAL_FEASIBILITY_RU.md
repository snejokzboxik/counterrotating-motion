# V13.3 — физическая реализуемость параметрической сетки

## Коэффициенты и перевод в напряжения

Использованы уже сохранённые и проверенные P4 FEM-базисы V13.1/V13.2 при `R=8 mm`: `c2=d2=0.7718255558274212`, `c4=0.5413395699439091`. В опорном протоколе `f=100 kHz`, `Q=+e`, `M0=3200.04652261404 Th`. Для `S=M0Ω²R²/e` напряжения соответствующих базисов восстанавливаются как `U2=βS/c2`, `VDC=αS/d2`, `U4=κS/c4`.

Реальные координаты электродов — `θj=30°j`, j=0…11. Использована сохранённая таблица электродных коэффициентов: `Q2j`, `C4j`, `S4j`. При основной относительной фазе `δ=0`:

```text
Vj(t) = Q2j [U2 cos(Ωt) + VDC]
      + U4 [C4j cos(Ωt) + S4j sin(Ωt)]
Vpeak,j = |VDC Q2j| + hypot(U2 Q2j + U4 C4j, U4 S4j).
```

Это максимум по непрерывной RF-фазе для данного электрода, а не сумма амплитуд разных источников без учета пространственных весов. Исходные коэффициенты взяты из V13.1 `electrode_voltage_peaks.csv`; геометрию и FEM-сетки повторно не создавали.

## Маска 250 В

Из 3 213 узлов `(α,β,η)` 1 699 (52.88%) удовлетворяют `max_j,t |Vj|≤250 V` при опорной массе/частоте/радиусе. По срезам:

| η | Узлов ≤250 В | Максимум напряжения по всей сетке |
|---:|---:|---:|
| −0.200 | 155/357 | 472.879 V |
| −0.100 | 183/357 | 426.439 V |
| −0.050 | 198/357 | 403.220 V |
| −0.025 | 206/357 | 391.610 V |
| 0 | 215/357 | 380.000 V |
| +0.025 | 206/357 | 391.610 V |
| +0.050 | 198/357 | 403.220 V |
| +0.100 | 183/357 | 426.439 V |
| +0.200 | 155/357 | 472.879 V |

Число 155/357 для `η=±0.20` совпадает по знаку амплитуды из-за симметрии пиков при `δ=0` и парной полярности электродного рисунка. Полная таблица, включая `U2,VDC,U4` и все 12 индивидуальных пиков, находится в `physical_feasibility_grid.csv`. Эта маска исключает физически недостижимые точки только из сравнений при заданном опорном протоколе; сами математические точки остаются на атласе.

Масштаб напряжений рассчитан для `M0/Q0`; при массовом скане фиксированные напряжения дают луч `(α,β,κ)∝1/(M/Q)`, но электрические пики остаются неизменными. Для иных массы, частоты или радиуса достижимая область меняется и здесь не смешивается с базовой картой.

## FEM-суперпозиция

Геометрию повторно не строили. На h50 использованы ранее сохранённые совместимые P4 базисы m=4 и m=2. На сохранённой h35 сетке отдельно решён только недостающий m=2 P4 базис; оба поля совпали по массивам узлов и элементов и имеют свои граничные условия с заземлённым корпусом. Градиенты и линейность сборки проверялись в V13.1, а в V13.3 выполнены проекции ведущих и высших гармоник и парные контрольные траектории на обоих полных FEM-полях. На 100 RF-периодах статусы h35/h50 совпали во всех 128 общих исходах; на 300 периодах выявлен один длительный mesh-sensitive исход. Подробные хеши, таблицы, неопределённость и численные параметры приведены в `FEM_VALIDATION_RU.md`.
