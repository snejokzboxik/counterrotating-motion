# Безразмерная модель V13.3

## Потенциал и масштабы

`ρ=(x_phys,y_phys)/R`, `τ=Ωt`, где `Ω=2πf`. Безразмерная функция потенциальной энергии для положительного иона:

```text
V(x,y,τ) = κ Re[(x+iy)^4 exp(-i(τ-δ))]
         + (β cos τ + α)(x²-y²).
```

Здесь `α=Q VDC d2/(M Ω²R²)`, `β=Q U2 c2/(M Ω²R²)`, `κ=Q U4 c4/(M Ω²R²)`, `η=κ/β` при `β≠0`. `δ` — относительная фаза вращающегося октуполя к стоячему квадрупольному RF. Инжекционная фаза `τ0` сдвигает абсолютное время обоих RF-полей: в правой части используются `τ+τ0`, тогда как `δ` остаётся неизменной. Это разные параметры.

## Декартовы уравнения

Пусть `z=x+iy`, `W=4κ z³ exp(-i(τ+τ0-δ)) + 2(β cos(τ+τ0)+α)z`. Тогда

```text
x'' = -Re(W)
y'' = +Im(W)
```

Это следует непосредственно из `r''=-∇V`; октупольная сила пропорциональна кубу координат. При `κ=0` получается RF/DC квадруполь. При `δ=0` уравнения совпадают с проверенной конвенцией V13.2. При `δ=π` RO-амплитуда меняет знак при неизменных `α,β`.

Линеаризация около центра:

```text
x'' + 2(α+β cos(τ+τ0)) x = 0
y'' - 2(α+β cos(τ+τ0)) y = 0.
```

Поэтому Q и Q+RO имеют одну и ту же линейную устойчивость при одинаковых `α,β`; нелинейные различия относятся к конечной апертуре и ненулевым начальным амплитудам.

## Связь с напряжениями электродов

Для опорного иона `M0/Q0`, заданных `R`, `Ω` и коэффициентов сохранённых FEM-базисов:

```text
S = M0 Ω² R² / Q0
U2 = β S/c2,    VDC = α S/d2,    U4 = κ S/c4.
```

Эти `U` — амплитуды соответствующих FEM пространственных базисов. Напряжения физического электрода `j` считаются по сохранённым `Q2_j,C4_j,S4_j`:

```text
Vj(τ) = Q2_j [U2 cos(τ)+VDC]
      + U4 [C4_j cos(τ-δ) + S4_j sin(τ-δ)].
```

Для каждой точки пиковое мгновенное напряжение находится как `max_τ |Vj(τ)|`; для чистых гармонических RF плюс DC это `|VDC Q2_j| + hypot(RF_cos_j,RF_sin_j)`. Физическая маска базового протокола требует `max_j,t |Vj|≤250 V`.

## Метрики и протокол атласа

`P_ret` — доля общих начальных состояний, не пересёкших наружу круговую апертуру `ρ=1` до `N_RF` периодов. Сохраняются фактическое время первого выхода и максимальный радиус; numerical error/incomplete имеют статус `unresolved`. Начальные скорости выражены в `dρ/dτ`, координаты — в `ρ`. Результаты по фазам `τ0=0,π/2` сначала показываются отдельно; их нельзя смешивать, пока не задано распределение RF-фазы.

Для фиксированных напряжений луч изменения массы/заряда масштабирует `(α,β,κ)` одним фактором `1/μ`, если остальные установки неизменны. Четырёхмерный аксептанс будет считаться отдельно на заявленном общем фазовом домене: для равномерного по площади диска `r≤7.5 mm` и скоростного диска, соответствующего фиксированной энергии 5 eV, с повторным преобразованием физических скоростей при каждой массе. Будут приведены `A4` в `m⁴ s⁻²`, `a4=A4/(R⁴Ω²)` и доля домена; V12 оценки не переиспользуются.
